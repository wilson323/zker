## 🔍 已知问题和限制

### 1. 异步操作等待

某些测试需要等待异步操作完成（如汇总更新），使用了简单的`time.Sleep()`。在生产环境中，应该使用更可靠的同步机制。

### 2. Docker依赖

测试依赖Docker运行MySQL容器，需要确保Docker服务已启动。

### 3. 测试执行时间

完整的测试套件可能需要30-60分钟，建议在CI/CD环境中运行，或者只运行特定的测试子集。

### 4. 资源清理

测试容器会在测试完成后自动清理，但如果测试异常退出，可能需要手动清理：
```bash
docker ps -a | grep mysql | awk '{print $1}' | xargs docker rm -f
```
