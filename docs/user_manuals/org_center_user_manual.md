## 第一章: 系统概述

### 1.1 组织中心功能介绍

组织中心是 Coze Studio 的核心人力资源管理模块，提供企业级组织架构管理能力。通过组织中心，您可以：

#### 核心功能

1. **组织架构管理**
   - 创建多层级组织结构（集团 → 公司 → 部门 → 团队）
   - 灵活调整组织架构
   - 可视化组织树形图

2. **人员管理**
   - 员工全生命周期管理（入职 → 转正 → 调岗 → 离职）
   - 员工信息维护
   - 批量导入导出

3. **HR业务流程**
   - 合同管理（签署、到期提醒）
   - 调岗管理（审批流程）
   - 离职管理（审批 + 交接）
   - 试用期管理（转正评估）

4. **岗位职级体系**
   - 岗位创建和管理
   - 职级体系维护
   - 岗位类别分类

5. **企业通讯录**
   - 组织架构目录
   - 员工信息查询
   - 智能搜索

#### 业务价值

- 🎯 **提升管理效率**: 自动化HR流程，减少手工操作
- 📊 **数据可视化**: 清晰的组织架构图和人员分布
- 🔒 **权限管控**: 细粒度的数据权限控制
- 📱 **移动办公**: 随时随地查询组织信息

### 2.1 创建组织

#### 功能说明

创建组织是建立组织架构的第一步。支持创建集团、公司、部门、团队等不同层级的组织节点。

#### 操作步骤

**步骤1: 进入组织管理页面**

1. 点击顶部导航栏的 **[组织管理]** 菜单
2. 进入组织管理列表页面

```
[🖼️ 截图占位符: 组织管理页面]
显示组织列表和新建按钮
```

**步骤2: 点击新建按钮**

1. 点击页面右上角的 **[+ 新建组织]** 按钮
2. 弹出"创建组织"对话框

```
[🖼️ 截图占位符: 创建组织对话框]
显示组织创建表单
```

**步骤3: 填写组织信息**

| 字段 | 说明 | 是否必填 | 示例 |
|------|------|---------|------|
| 组织名称 | 组织的名称 | ✅ 必填 | 华东分公司 |
| 组织编码 | 组织的唯一编码 | ✅ 必填 | HUADONG_001 |
| 组织类型 | 集团/公司/部门/团队 | ✅ 必填 | 公司 |
| 上级组织 | 选择父级组织 | ✅ 必填 | 总部集团 |
| 负责人 | 组织负责人 | ❌ 选填 | 张三 |
| 联系电话 | 联系电话 | ❌ 选填 | 021-12345678 |
| 地址 | 组织地址 | ❌ 选填 | 上海市浦东新区 |
| 描述 | 组织描述 | ❌ 选填 | 华东地区业务中心 |

⚠️ **注意**:
- 组织编码全局唯一，创建后不可修改
- 组织类型决定节点的层级
- 上级组织决定组织在树中的位置

**步骤4: 提交创建**

1. 填写完成后，点击 **[确定]** 按钮
2. 系统验证表单
3. 创建成功后，自动跳转到组织详情页

```
[🖼️ 截图占位符: 组织详情页]
显示刚创建的组织信息
```

#### 验证规则

- ✅ 组织名称: 1-100字符，不能重复
- ✅ 组织编码: 1-50字符，字母数字下划线，全局唯一
- ✅ 组织类型: 必须选择有效类型
- ✅ 上级组织: 必须选择已存在的组织

#### 常见错误

| 错误信息 | 原因 | 解决方案 |
|---------|------|---------|
| 组织编码已存在 | 编码重复 | 更换唯一的编码 |
| 上级组织不存在 | 组织已被删除 | 选择其他上级组织 |
| 无权限创建组织 | 权限不足 | 联系管理员授权 |

### 2.3 移动组织

#### 功能说明

移动组织可以调整组织在组织树中的位置，改变其上级组织。

#### 操作步骤

**步骤1: 选择要移动的组织**

1. 在组织管理页面，找到要移动的组织
2. 点击操作列的 **[移动]** 按钮

```
[🖼️ 截图占位符: 移动按钮]
```

**步骤2: 选择新的上级组织**

1. 弹出"移动组织"对话框
2. 在组织树中选择新的上级组织

```
[🖼️ 截图占位符: 移动组织对话框]
显示组织树选择器
```

**步骤3: 确认移动**

1. 选择新上级后，点击 **[确定]** 按钮
2. 系统验证移动合法性
3. 移动成功后，组织树自动刷新

⚠️ **重要注意事项**:

1. **不能移动到自己的子节点**: 避免循环引用
2. **移动会移动所有子节点**: 整个子树一起移动
3. **确认权限**: 需要有源组织和目标组织的管理权限
4. **数据影响**: 移动不影响员工的部门和岗位关系

💡 **最佳实践**:
- 移动前先确认目标位置
- 建议在组织调整期集中操作
- 移动后通知相关人员

### 2.4 删除组织

#### 功能说明

删除组织节点。删除前系统会检查是否有子组织和员工，确保数据安全。

#### 限制说明

⚠️ **删除限制**:

1. **有子组织**: 必须先删除或移动所有子组织
2. **有关联员工**: 必须先将员工调离或删除
3. **有关联数据**: 部门、岗位等数据需要先处理

#### 操作步骤

**步骤1: 选择要删除的组织**

1. 在组织管理页面，找到要删除的组织
2. 点击操作列的 **[删除]** 按钮

```
[🖼️ 截图占位符: 删除按钮]
```

**步骤2: 确认删除**

1. 弹出删除确认对话框
2. 显示删除影响和限制检查结果

```
[🖼️ 截图占位符: 删除确认对话框]
```

**步骤3: 执行删除**

1. 确认无误后，点击 **[确认删除]** 按钮
2. 系统执行软删除（数据保留，不物理删除）
3. 显示删除成功提示

#### 删除检查清单

系统会自动检查以下项目：

- [ ] 无子组织
- [ ] 无关联员工
- [ ] 无关联部门
- [ ] 无关联岗位
- [ ] 无关联HR流程数据

❌ **如果有未完成项，删除操作会被拒绝**

💡 **建议**: 删除前先导出相关数据作为备份

### 2.6 常见问题FAQ

#### Q1: 组织编码可以修改吗？

**A**: 不可以。组织编码是组织的唯一标识，创建后不可修改。如需更改，只能删除后重新创建（⚠️ 删除会影响关联数据）。

#### Q2: 如何批量创建组织？

**A**: 目前暂不支持批量创建，需要逐个创建。建议使用Excel模板提前规划好组织架构和编码。

#### Q3: 组织层级有限制吗？

**A**: 理论上无限制，但建议不超过5层，以保证系统性能和用户体验。

#### Q4: 移动组织会影响员工吗？

**A**: 不会。移动组织只调整组织在树中的位置，不影响员工的所属关系。

#### Q5: 如何撤销已删除的组织？

**A**: 删除是软删除，数据仍保留在数据库。请联系系统管理员恢复。

#### Q6: 组织负责人有什么权限？

**A**: 组织负责人可以查看和管理本组织及其子组织的数据（取决于权限配置）。

#### Q7: 为什么找不到移动按钮？

**A**: 可能原因：
1. 权限不足（需要组织管理权限）
2. 组织被锁定（联系管理员）
3. 浏览器缓存问题（清除缓存重试）

#### Q8: 组织架构图可以导出吗？

**A**: 可以。点击右上角的 **[导出图片]** 按钮，可选择PNG或PDF格式。

#### 功能说明

将通讯录导出为Excel或PDF文件，便于线下使用。

#### 操作步骤

1. 在通讯录页面，点击 **[导出]** 按钮
2. 选择导出格式（Excel/PDF）
3. 选择导出范围（全部组织/当前组织）
4. 点击 **[确认导出]**
5. 系统生成文件并自动下载

```
[🖼️ 截图占位符: 导出通讯录对话框]
```

#### 导出内容

导出文件包含以下信息：

| 字段 | 说明 |
|------|------|
| 组织 | 所属组织 |
| 部门 | 所属部门 |
| 工号 | 员工工号 |
| 姓名 | 员工姓名 |
| 岗位 | 岗位名称 |
| 手机 | 联系电话 |
| 邮箱 | 工作邮箱 |
| 地址 | 工作地址 |

⚠️ **注意**: 敏感信息（身份证号、薪资）不会导出
