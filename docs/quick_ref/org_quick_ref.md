## 📊 组织管理

### 创建组织

```
步骤:
1. 组织管理 → [+ 新建组织]
2. 填写必填字段:
   - 组织名称 (例: 华东分公司)
   - 组织编码 (例: HUADONG_001) ⚠️ 必须唯一，不可修改
   - 组织类型 (集团/公司/部门/团队)
   - 上级组织
3. 填写选填字段: 负责人、电话、地址
4. [确定] 保存
```

### 编辑组织

```
步骤:
1. 组织列表 → 找到组织 → [编辑]
2. 修改字段 (⚠️ 编码、类型、上级不可编辑)
3. [保存]
```

### 移动组织

```
步骤:
1. 组织列表 → [移动]
2. 选择新上级组织
3. [确定]

⚠️ 注意:
- 不能移动到自己的子节点
- 会同时移动所有子节点
- 不影响员工数据
```

### 删除组织

```
步骤:
1. 组织列表 → [删除]
2. 系统检查: 无子组织、无员工
3. [确认删除]

⚠️ 软删除，数据仍保留，可联系管理员恢复
```

## 👥 员工管理

### 员工入职

```
步骤:
1. 员工管理 → [+ 员工入职]
2. 填写必填字段:
   - 姓名
   - 工号 (⚠️ 必须唯一)
   - 手机
   - 邮箱
   - 所属组织、部门、岗位
   - 员工类型 (全职/兼职/实习)
   - 入职日期
3. 填写选填字段: 性别、学历、银行账户等
4. 上传证件照
5. [保存] → 状态自动设为 [试用期]
6. [签订合同] (详见HR管理)
```

### 编辑员工

```
步骤:
1. 员工列表 → 点击姓名 → 详情页
2. [编辑信息]
3. 修改字段
4. [保存]
```

### 员工转正

```
步骤:
1. 员工详情页 → [转正申请]
2. 填写转正评估:
   - 试用期表现
   - 考核结果 (通过/不通过)
   - 转正日期
   - 转正后职级
3. 提交审批
4. 审批通过 → 状态变更为 [正式员工]
```

### 批量导入

```
步骤:
1. 员工管理 → [批量导入] → [下载模板]
2. 填写Excel:
   | 工号 | 姓名 | 手机 | 邮箱 | 部门 | 岗位 | 入职日期 |
   |------|------|------|------|------|------|---------|
   | EMP001 | 张三 | 138xxx | zhangsan@xx.com | 研发部 | 工程师 | 2025-01-01 |
3. [选择文件] → [上传并导入]
4. 验证数据 → [确认导入]

⚠️ 注意:
- 日期格式: YYYY-MM-DD
- 部门和岗位必须已存在
```

## 📝 HR管理

### 签订合同

```
步骤:
1. 员工详情页 → [签订合同]
2. 填写合同信息:
   - 合同类型 (固定/无固定/实习)
   - 开始日期、结束日期
   - 试用期 (月)
   - 工作地点
   - 基本工资
   - 合同附件 (上传PDF)
3. [提交]
4. 员工签署 (电子签名)
5. 公司签署
6. 合同生效 → 状态: [已签署]

⚠️ 系统会在到期前30天自动提醒
```

### 调岗流程

```
步骤:
1. 员工详情页 → [调岗申请]
2. 填写调岗信息:
   - 调岗类型 (晋升/降职/调动)
   - 新部门、新岗位、新职级
   - 生效日期
   - 调岗原因
   - 新薪资 (如调整)
3. [提交] → 审批流程:
   - 原部门经理审批
   - 新部门经理审批
   - HR审批
4. 审批通过 → 到达生效日期 → 自动更新员工信息
```

### 离职流程

```
步骤:
1. 员工详情页 → [离职申请]
2. 填写离职信息:
   - 离职类型 (主动/被动)
   - 离职原因
   - 最后工作日
3. [提交] → 审批流程:
   - 部门经理审批
   - HR审批
4. 审批通过 → 工作交接:
   - 文档资料
   - 系统权限
   - 资产设备
   - 客户关系
5. 逐项完成 → 交接人确认 → HR确认
6. 到达最后工作日 → 状态变更为 [离职]
7. 生成离职证明
```

## 📖 通讯录

### 查看通讯录

```
步骤:
1. 通讯录 → 选择组织节点
2. 右侧显示该组织所有员工
3. 点击员工姓名 → 查看员工卡片
```

### 搜索员工

```
支持搜索:
- 员工姓名 (中文、拼音)
- 员工工号
- 手机号码
- 邮箱地址

例: 输入"zhangsan"或"zs"都可以找到张三
```

### 导出通讯录

```
步骤:
1. 通讯录 → [导出]
2. 选择格式 (Excel/PDF)
3. 选择范围 (全部/当前组织)
4. [确认导出] → 自动下载

⚠️ 敏感信息（身份证号、薪资）不导出
```

## ❓ 常见问题快速解答

### Q: 组织编码可以修改吗？
**A**: 不可以。组织编码是唯一标识，创建后不可修改。如需更改，只能删除后重建。

### Q: 员工工号可以重复吗？
**A**: 不可以。工号必须全局唯一。

### Q: 如何批量导入员工？
**A**: 员工管理 → [批量导入] → 下载模板 → 填写数据 → 上传导入

### Q: 合同到期系统会提醒吗？
**A**: 会的。系统会在合同到期前30天自动提醒员工、HR、部门经理。

### Q: 移动组织会影响员工吗？
**A**: 不会。移动组织只调整树中的位置，不影响员工数据。

### Q: 如何撤销已删除的组织？
**A**: 删除是软删除，数据仍保留。请联系系统管理员恢复。

### Q: 批量导入失败怎么办？
**A**: 检查Excel格式，确保必填字段不为空，部门岗位已存在。

### Q: 调岗后薪资什么时候生效？
**A**: 到达调岗生效日期后生效。
