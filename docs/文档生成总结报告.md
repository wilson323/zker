### 2. 概要设计说明书

**文档路径：** `docs/design/概要设计说明书.md`

**文档内容概览：**

✅ **系统概述**
- 设计目标：高内聚低耦合、可扩展性、高可用性、安全性
- 系统范围：前后端应用、数据库、基础设施

✅ **系统架构设计**
- 架构风格：分层微服务架构 + DDD
- 五层架构：
  - 客户端层（React SPA）
  - 接入层（Nginx）
  - 应用层（Go 微服务）
  - 领域层（Domain）
  - 基础设施层（MySQL、Redis、ES、Milvus 等）
- 关键架构模式：
  - 适配器模式（解耦依赖）
  - 仓储模式（数据访问抽象）
  - 事件驱动架构（异步解耦）

✅ **模块设计**

**前端模块（135+ 个包）：**
- Level 1：架构层（API 适配器、HTTP 客户端、状态管理、国际化）
- Level 2：公共层（聊天区域、表格、业务组件）
- Level 3：业务层（Agent IDE、Workflow、Studio、Data）
- Level 4：应用层（zker 主应用）

**后端模块：**
- 应用服务：Agent、Conversation、Workflow、Knowledge、Plugin、User、Publish
- 领域模型：Agent 聚合根、Workflow DAG、知识库领域、对话领域

✅ **数据库设计**
- 数据库选型：MySQL 8.4.5、Redis 8.0、Elasticsearch 8.18.0、Milvus v2.5.10
- 数据库分层策略：核心业务 → MySQL、热点数据 → Redis、搜索 → ES、向量 → Milvus
- 核心表概念模型（10+ 个实体）：用户、空间、Agent、对话、消息、工作流、知识库、文档

✅ **接口设计**
- API 设计原则：RESTful、版本管理、统一响应格式
- 核心 API：Agent 管理、对话 API、工作流 API
- WebSocket 接口、Webhook 接口

✅ **技术选型**
- 前端：React 18、TypeScript 5.0、Rsbuild、Rush.js、Semi Design、Zustand
- 后端：Go 1.23+、Hertz、GORM、Wire、Zap
- 基础设施：MySQL、Redis、Elasticsearch、Milvus、MinIO、NSQ、etcd
- 开发工具：ESLint、Golangci-lint、Vitest、Docker、GitHub Actions

✅ **部署架构**
- 部署拓扑图（Docker Compose）
- 容器编排、网络配置
- 资源规划（最小/推荐配置）
- 高可用方案（MySQL 主从、Redis 哨兵、ES 集群）
- 备份与恢复（全量 + 增量、RTO ≤ 1 小时、RPO ≤ 5 分钟）

**文档内容概览：**

✅ **模块详细设计**

   - TypeScript 类型定义：Agent、ModelConfig、MemoryConfig

   - Zustand Store 设计
   - UserStore、SpaceStore、AgentStore、ConversationStore
   - 状态持久化（localStorage）

3. **工作流画布模块 (`@coze-workflow/fabric-canvas`)**
   - 基于 FlowGram 的编辑器组件
   - 节点类型定义（Start、End、Variable、Condition、LLM、API Call、Code）
   - 工具栏操作、自动保存

**后端模块：**
1. **Agent 应用服务**
   - Service 层实现
   - CRUD 业务逻辑编排
   - DTO 转换、验证器
   - 领域事件发布

✅ **数据库物理设计**

**表结构详细设计（10+ 个表）：**
1. `users` - 用户表（bcrypt 密码、索引）
2. `spaces` - 空间表
3. `space_members` - 空间成员表
4. `bots` - Agent 表（JSON 配置字段）
5. `bot_resources` - Agent 资源关联表
6. `bot_variables` - Agent 变量表
7. `conversations` - 对话表
8. `messages` - 消息表（JSON 元数据）
9. `workflows` - 工作流表（JSON DAG）
10. `workflow_executions` - 工作流执行记录表
11. `knowledge_bases` - 知识库表
12. `documents` - 文档表
13. `document_chunks` - 文档切片表

**索引优化策略：**
- 复合索引：`idx_bot_space_status_time`
- 全文索引：`ft_name_desc`
- 分区策略：消息表按月分区

✅ **API 详细设计**

**通用规范：**
- Base URL、认证方式、请求头、响应格式
- 错误码规范（5 位数字）

**Agent API 详细定义：**
- 创建 Agent：完整请求/响应示例
- 发布 Agent：版本管理

**Chat API 详细定义：**
- 发送消息（SSE 流式响应）

**Workflow API 详细定义：**
- 执行工作流（异步/同步）
- 查询执行状态

✅ **核心算法设计**

**对话记忆算法：**
- 滑动窗口实现
- 消息过期清理

**知识库检索算法：**
- 混合检索（向量 + 全文）
- 结果合并与重排序

**工作流 DAG 调度算法：**
- 拓扑排序执行
- 并行执行、循环依赖检测

✅ **用户界面设计**

**界面设计原则：**
- 一致性、响应式、可访问性、性能

**页面原型：**
- Agent 配置页面（基本信息、提示词、模型配置、能力、高级设置）
- 工作流编辑页面（节点面板、画布、属性面板、工具栏）

**组件库：**
- Button、Input、Select、Modal、Table、Upload、CodeEditor

✅ **安全设计**

**认证与授权：**
- JWT Token 结构
- RBAC 权限模型
- 权限检查中间件

**数据加密：**
- 密码加密（bcrypt）
- 敏感数据加密（AES-256）

**输入验证：**
- SQL 注入防护（参数化查询）
- XSS 防护（HTML 转义）

**API 限流：**
- 令牌桶算法实现

✅ **性能优化设计**

**缓存策略：**
- 多级缓存（L1 进程内 + L2 Redis）

- 批量查询（避免 N+1）

**前端性能优化：**
