## 🏗️ 架构设计

### 1. DDD分层架构

```
backend/domain/knowledgegraph/
├── entity/                 # 实体层（领域模型）
│   ├── graph_entity.go            # 图实体
│   ├── graph_relationship.go      # 图关系
│   └── graph_query.go             # 图查询
├── repository/             # 仓储层（数据访问）
│   ├── graph_entity_repository.go
│   ├── graph_relationship_repository.go
│   └── graph_query_repository.go
└── service/                # 服务层（业务逻辑）
    ├── graph_construction_service.go    # 图谱构建
    ├── graph_query_service.go           # 图谱查询
    ├── graph_inference_service.go       # 图谱推理
    └── graph_visualization_service.go   # 可视化数据

backend/api/handler/coze/knowledgegraph/
├── graph_construction_handler.go       # 构建API
└── graph_query_handler.go              # 查询API
```

### 2. 数据库设计

使用MySQL 8.4.5存储图数据（邻接表模式），兼容GORM:

**表1: graph_entities**（图实体）
```sql
CREATE TABLE graph_entities (
    id VARCHAR(36) PRIMARY KEY,
    tenant_id VARCHAR(36) NOT NULL,
    entity_type VARCHAR(50) NOT NULL,      -- person, org, location, concept, etc.
    entity_name VARCHAR(200) NOT NULL,
    properties JSON,                       -- 实体属性
    embedding JSON,                        -- 向量嵌入
    created_at BIGINT NOT NULL,
    updated_at BIGINT NOT NULL,
    deleted_at BIGINT,

    INDEX idx_tenant_id (tenant_id),
    INDEX idx_entity_type (entity_type),
    INDEX idx_entity_name (entity_name),
    INDEX idx_tenant_type (tenant_id, entity_type)
);
```

**表2: graph_relationships**（图关系）
```sql
CREATE TABLE graph_relationships (
    id VARCHAR(36) PRIMARY KEY,
    tenant_id VARCHAR(36) NOT NULL,
    source_entity_id VARCHAR(36) NOT NULL,
    target_entity_id VARCHAR(36) NOT NULL,
    relation_type VARCHAR(50) NOT NULL,    -- works_for, knows, located_in, etc.
    properties JSON,
    weight FLOAT DEFAULT 1.0,
    created_at BIGINT NOT NULL,
    deleted_at BIGINT,

    INDEX idx_tenant_id (tenant_id),
    INDEX idx_source (source_entity_id),
    INDEX idx_target (target_entity_id),
    INDEX idx_relation (relation_type),
    INDEX idx_tenant_source (tenant_id, source_entity_id),
    INDEX idx_tenant_target (tenant_id, target_entity_id),
    INDEX idx_tenant_relation (tenant_id, relation_type)
);
```

**表3: graph_queries**（预定义查询）
```sql
CREATE TABLE graph_queries (
    id VARCHAR(36) PRIMARY KEY,
    tenant_id VARCHAR(36) NOT NULL,
    query_name VARCHAR(100) NOT NULL,
    query_text TEXT NOT NULL,              -- Cypher查询语句
    description TEXT,
    variables JSON,
    is_public TINYINT(1) DEFAULT FALSE,
    created_by VARCHAR(36) NOT NULL,
    created_at BIGINT NOT NULL,
    updated_at BIGINT NOT NULL,
    deleted_at BIGINT,

    INDEX idx_tenant_id (tenant_id)
);
```

## 🔧 核心功能实现

### 1. GraphConstructionService（图谱构建服务）

**职责**: 从文本中抽取实体和关系，构建知识图谱

**核心方法**:
```go
// 从文本构建完整图谱
func (s *GraphConstructionService) BuildGraphFromText(ctx context.Context, tenantID, text string) error

// 抽取实体（使用LLM）
func (s *GraphConstructionService) ExtractEntities(ctx context.Context, tenantID, text string) ([]*GraphEntity, error)

// 抽取关系（使用LLM）
func (s *GraphConstructionService) ExtractRelationships(ctx context.Context, tenantID string, text string, entities []*GraphEntity) ([]*GraphRelationship, error)

// 批量添加实体/关系
func (s *GraphConstructionService) AddEntities(ctx context.Context, entities []*GraphEntity) error
func (s *GraphConstructionService) AddRelationships(ctx context.Context, relationships []*GraphRelationship) error
```

**LLM提示词设计**:
- 实体抽取提示词: 支持7种实体类型（person, organization, location, concept, event, product, document）
- 关系抽取提示词: 支持25+种关系类型（works_for, knows, located_in, part_of, etc.）

**批量处理优化**:
- 实体批量插入: 每批1000条
- 关系批量插入: 每批1000条
- 避免N+1查询: 使用MGetByID

### 2. GraphQueryService（图谱查询服务）

**职责**: 执行图谱查询，获取实体、关系、子图、路径

**核心方法**:
```go
// 查询单个实体
func (s *GraphQueryService) QueryEntity(ctx context.Context, entityID string) (*GraphEntity, error)

// 查询N度邻居（BFS遍历）
func (s *GraphQueryService) QueryNeighbors(ctx context.Context, entityID string, depth int) (*GraphSubgraph, error)

// 查询两个实体之间的路径（BFS最短路径）
func (s *GraphQueryService) QueryPath(ctx context.Context, sourceID, targetID string, maxDepth int) ([]*GraphPath, error)

// 搜索实体
func (s *GraphQueryService) SearchEntities(ctx context.Context, tenantID, keyword string, entityType EntityType, limit int) ([]*GraphEntity, error)

// 获取图谱统计信息
func (s *GraphQueryService) GetGraphStatistics(ctx context.Context, tenantID string) (*GraphStatistics, error)
```

**查询优化**:
- BFS遍历优化: 使用队列和visited map避免重复访问
- 邻居查询: 使用ListNeighbors双向查询（出边+入边）
- 统计信息: 计算平均度数和图密度

### 3. GraphInferenceService（图谱推理服务）

**职责**: 基于图谱进行推理，推断潜在关系、实体类型、相似实体

**核心方法**:
```go
// 推断两个实体之间的关系
func (s *GraphInferenceService) InferRelationship(ctx context.Context, entity1ID, entity2ID string) (*GraphRelationship, error)

// 推断实体类型
func (s *GraphInferenceService) InferEntityType(ctx context.Context, tenantID, text string) (EntityType, error)

// 补全子图（推断缺失的关系）
func (s *GraphInferenceService) CompleteSubgraph(ctx context.Context, entityID string) (*GraphSubgraph, error)

// 推荐相关实体（基于2跳邻居）
func (s *GraphInferenceService) RecommendEntities(ctx context.Context, entityID string, topK int) ([]*GraphEntity, error)

// 查找相似实体（Jaccard相似度）
func (s *GraphInferenceService) FindSimilarEntities(ctx context.Context, entityID string, topK int) ([]*GraphEntity, error)
```

**推理算法**:
- **关系推断**:
  - LLM推断: 使用Claude 3.5
  - 规则推断: 基于实体类型的规则引擎（降级方案）
- **实体推荐**: 基于2跳邻居的加权评分
- **相似度计算**: Jaccard相似度（类型相似度30% + 属性相似度70%）

### 4. GraphVisualizationService（可视化数据生成服务）

**职责**: 生成前端可视化所需的JSON格式数据

**核心方法**:
```go
// 生成可视化数据
func (s *GraphVisualizationService) GenerateGraphData(ctx context.Context, tenantID string, centerEntityID string, depth int) (*VisualizationData, error)

// 生成完整图谱
func (s *GraphVisualizationService) generateFullGraph(ctx context.Context, tenantID string, limit int) (*VisualizationData, error)

// 生成子图（BFS遍历）
func (s *GraphVisualizationService) generateSubGraph(ctx context.Context, centerEntityID string, depth int) (*VisualizationData, error)

// 生成路径可视化
func (s *GraphVisualizationService) GeneratePathVisualization(ctx context.Context, path *GraphPath) (*VisualizationData, error)

// 生成力导向布局数据
func (s *GraphVisualizationService) GenerateForceLayoutData(ctx context.Context, tenantID string, limit int) (*VisualizationData, error)
```

**可视化数据格式**:
```typescript
interface VisualizationData {
  nodes: VisNode[];      // 节点数组
  links: VisLink[];      // 链接数组
}

interface VisNode {
  id: string;
  label: string;
  type: EntityType;
  size: number;          // 节点大小（基于度数）
  color: string;         // 节点颜色（基于类型）
  properties: EntityProperties;
  x?: number;
  y?: number;
}

interface VisLink {
  source: string;        // 源节点ID
  target: string;        // 目标节点ID
  label: string;         // 关系标签
  type: RelationType;
  weight: number;
  color: string;
}
```

**颜色映射**:
- person: #4ECDC4（青色）
- organization: #FF6B6B（红色）
- location: #95E1D3（绿色）
- concept: #F38181（粉色）
- event: #AA96DA（紫色）
- product: #FCBAD3（粉紫）
- document: #FFFFD2（黄色）
