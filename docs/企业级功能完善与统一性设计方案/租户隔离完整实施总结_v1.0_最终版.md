}

## 🚀 使用方式

### 1. 应用启动时初始化

```go
import (
    "github.com/coze-studio/coze-studio/backend/api/middleware"
    "github.com/coze-studio/coze-studio/backend/domain/tenant/service"
    "github.com/coze-studio/coze-studio/backend/infra/cache"
)

func main() {
    // 初始化租户服务和Redis
    tenantService := service.NewTenantService(...)
    redisClient := cache.NewRedis(...)

    // 注入租户中间件依赖
    middleware.InitTenantMiddleware(tenantService, redisClient)

    // 启用租户隔离中间件
    h.Use(middleware.TenantIsolationMiddleware())

    h.Run(":8888")
}
```

### 2. API调用方式

```bash
# 方式1: 通过HTTP Header（推荐）
curl -X GET http://localhost:8888/api/bots \
  -H "X-Tenant-ID: individual-user-1" \
  -H "Authorization: Bearer your-token"

# 方式2: 通过Session（包含tenant_id）
curl -X GET http://localhost:8888/api/bots \
  -H "Cookie: session_key=your-session"

# 方式3: 通过JWT Token（TODO：包含tenant_id）
curl -X GET http://localhost:8888/api/bots \
  -H "Authorization: Bearer your-jwt-token"
```

### 3. 业务代码中使用

```go
func ListBots(ctx context.Context, c *app.RequestContext) {
    // 获取tenant_id
    tenantID := middleware.GetTenantIDFromContext(ctx)
    // 或强制要求
    tenantID := middleware.MustGetTenantIDFromContext(ctx)

    // 查询数据（自动添加tenant_id过滤）
    bots, err := botService.ListByTenant(ctx, tenantID)
    // ...
}
```
