## 1. 员工档案扩展

### 1.1 添加工作经历

**场景**: 员工入职时填写历史工作经历

```bash
curl -X POST http://localhost:8080/api/v1/org/employees/{user_id}/work_experiences \
  -H "Content-Type: application/json" \
  -d '{
    "tenant_id": "tenant-001",
    "company_name": "腾讯科技",
    "position": "高级软件工程师",
    "start_date": "2020-01-01",
    "end_date": "2022-12-31",
    "description": "负责微信支付系统开发"
  }'
```

**响应**:
```json
{
  "message": "success"
}
```

## 2. 虚拟组织管理

### 2.1 创建项目组

**场景**: 为临时项目创建虚拟组织

```bash
curl -X POST http://localhost:8080/api/v1/org/virtual-organizations \
  -H "Content-Type: application/json" \
  -d '{
    "tenant_id": "tenant-001",
    "name": "AI模型优化项目组",
    "description": "负责大语言模型性能优化",
    "type": "PROJECT",
    "owner_id": "user-001"
  }'
```

**响应**:
```json
{
  "virtual_org_id": "vo-1234567890",
  "message": "success"
}
```

### 2.2 添加项目组成员

**场景**: 邀请跨部门人员参与项目

```bash
curl -X POST http://localhost:8080/api/v1/org/virtual-organizations/{org_id}/members \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "user-002",
    "role": "MEMBER"
  }'
```

**角色说明**:
- `OWNER`: 所有者,拥有所有权限
- `ADMIN`: 管理员,可以管理成员
- `MEMBER`: 普通成员,只能查看和参与

### 2.3 列出项目组成员

```bash
curl -X GET http://localhost:8080/api/v1/org/virtual-organizations/{org_id}/members
```

**响应**:
```json
{
  "members": [
    {
      "user_id": "user-001",
      "role": "OWNER",
      "joined_at": 1704067200000
    },
    {
      "user_id": "user-002",
      "role": "MEMBER",
      "joined_at": 1704153600000
    }
  ]
}
```

### 2.4 按类型筛选虚拟组织

```bash
# 只查看项目组
curl -X GET "http://localhost:8080/api/v1/org/virtual-organizations?tenant_id=tenant-001&type=PROJECT"

# 只查看任务组
curl -X GET "http://localhost:8080/api/v1/org/virtual-organizations?tenant_id=tenant-001&type=TASK_FORCE"
```

## 3. 矩阵组织管理

### 3.1 创建矩阵汇报关系

**场景**: 员工同时向职能经理和项目经理汇报

```bash
# 职能汇报关系(直线经理)
curl -X POST http://localhost:8080/api/v1/org/matrix-reportings \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "user-001",
    "reporting_type": "FUNCTIONAL",
    "supervisor_id": "user-002",
    "organization_id": "org-001",
    "effective_date": "2024-01-01",
    "is_primary": true
  }'

# 项目汇报关系(项目经理)
curl -X POST http://localhost:8080/api/v1/org/matrix-reportings \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "user-001",
    "reporting_type": "PROJECT",
    "supervisor_id": "user-003",
    "organization_id": "org-002",
    "effective_date": "2024-01-01",
    "is_primary": false
  }'
```

**汇报类型说明**:
- `FUNCTIONAL`: 职能汇报,传统的直线管理关系
- `PROJECT`: 项目汇报,项目期间的横向汇报
- `DOTTED`: 虚线汇报,非正式的咨询关系

### 3.2 查看所有上级

**场景**: 员工需要知道向哪些人汇报

```bash
curl -X GET http://localhost:8080/api/v1/org/employees/{user_id}/supervisors
```

**场景**: 管理者查看所有下属(包括矩阵式)

```bash

# 只包含职能汇报的下属
```

## 4. API调用示例

### 4.1 Go SDK示例

```go
package main

import (
    "context"
    "fmt"
    "time"

    "github.com/coze-dev/coze-studio/backend/domain/org/entity"
    "github.com/coze-dev/coze-studio/backend/domain/org/service"
)

func main() {
    ctx := context.Background()

    // 1. 添加工作经历
    profileService := service.NewMemberProfileService(...)

    exp := &entity.WorkExperience{
        UserID:      "user-001",
        TenantID:    "tenant-001",
        CompanyName: "腾讯科技",
        Position:    "高级软件工程师",
        StartDate:   time.Date(2020, 1, 1, 0, 0, 0, 0, time.Local).UnixMilli(),
        EndDate:     timePtr(time.Date(2022, 12, 31, 0, 0, 0, 0, time.Local).UnixMilli()),
    }

    if err := profileService.AddWorkExperience(ctx, exp); err != nil {
        fmt.Printf("添加工作经历失败: %v\n", err)
        return
    }

    // 2. 生成简历
    resume, err := profileService.GenerateResume(ctx, "user-001")
    if err != nil {
        fmt.Printf("生成简历失败: %v\n", err)
        return
    }

    fmt.Printf("员工: %s, 工作年限: %d年\n",
        resume.Employee.EmpName,
        resume.GetTotalWorkYears())

    // 3. 创建虚拟组织
    virtualOrgService := service.NewVirtualOrganizationService(...)

    org := &entity.VirtualOrganization{
        TenantID:    "tenant-001",
        Name:        "AI模型优化项目组",
        Type:        entity.VirtualOrgTypeProject,
        OwnerID:     "user-001",
    }

    if err := virtualOrgService.CreateVirtualOrg(ctx, org); err != nil {
        fmt.Printf("创建虚拟组织失败: %v\n", err)
        return
    }

    // 4. 查看上级
    matrixOrgService := service.NewMatrixOrganizationService(...)

    supervisors, err := matrixOrgService.GetSupervisors(ctx, "user-001")
    if err != nil {
        fmt.Printf("获取上级失败: %v\n", err)
        return
    }

    for _, sup := range supervisors {
        fmt.Printf("上级: %s (%s)\n", sup.SupervisorName, sup.ReportingType)
    }
}

func timePtr(t int64) *int64 {
    return &t
}
```

## 5. 常见问题

### Q1: 虚拟组织和传统部门有什么区别?

**A**:
- **传统部门**: 正式的组织架构,用于职能管理,有明确的汇报关系
- **虚拟组织**: 灵活的临时性组织,用于项目协作或兴趣社区,成员可以属于多个虚拟组织

### Q2: 一个员工可以有多少个汇报关系?

**A**:
- **主要汇报关系**: 只能有一个(is_primary=true)
- **次要汇报关系**: 可以有多个,包括项目汇报和虚线汇报

### Q3: 如何处理矩阵组织中的权限冲突?

**A**:
- 职能汇报(直线经理)拥有最终决策权
- 项目汇报(项目经理)在项目范围内有决策权
- 系统会计算所有汇报路径,确保权限正确传递

### Q4: 虚拟组织归档后,成员还能访问吗?

**A**:
- 归档后,虚拟组织变为只读状态
- 成员可以查看历史记录,但不能进行编辑操作
- 可以重新激活已归档的组织

### Q5: 如何批量导入员工档案?

**A**:
- 使用CSV文件批量导入
- 调用`/api/v1/org/employees/batch-import`接口
- 支持工作经历、教育经历、技能的批量导入

### Q6: 技能认证的流程是什么?

**A**:
1. 员工自评添加技能
2. 提交认证申请
3. 管理者或专家审核
4. 通过后标记为certified=true
