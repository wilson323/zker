## 🔄 状态管理

**包路径**: `@coze-studio/stores`

### Zustand Stores

| Store | 说明 | 主要方法 |
|-------|------|---------|
| **authStore** | 认证状态 | `login()`, `logout()`, `updateUserInfo()`, `setToken()` |
| **tenantStore** | 租户状态 | `setCurrentTenant()`, `setAccessibleTenants()` |
| **permissionStore** | 权限状态 | `checkPermission()`, `setPermissions()` |
| **uiStore** | UI状态 | `setThemeMode()`, `addToast()`, `toggleSidebar()` |

### 使用示例

```typescript
import { useAuthStore, useTenantStore } from '@coze-studio/stores';

function MyComponent() {
  const { user, isAuthenticated } = useAuthStore();
  const { currentTenant } = useTenantStore();

  if (!isAuthenticated) {
    return <div>请先登录</div>;
  }

  return <div>当前租户: {currentTenant?.tenant_name}</div>;
}
```

## 🎨 设计规范

### 设计令牌

```typescript
import { designTokens } from '@coze-studio/ui-components';

// 颜色
designTokens.colors.primary[6]; // #1890ff
designTokens.colors.success[6]; // #52c41a
designTokens.colors.warning[6]; // #faad14
designTokens.colors.error[6];   // #f5222d

// 间距
designTokens.spacing[1];  // 4px
designTokens.spacing[2];  // 8px
designTokens.spacing[4];  // 16px

// 圆角
designTokens.borderRadius.md;   // 8px
designTokens.borderRadius.lg;   // 12px

// 阴影
designTokens.shadows.md; // 中等阴影
designTokens.shadows.lg; // 大阴影
```

### 组件开发规范

✅ **SOLID 原则**：
- 单一职责：每个组件只做一件事
- 开放封闭：对扩展开放，对修改关闭
- 依赖倒置：依赖抽象（Props接口）而非具体实现

✅ **性能优化**：
- 使用 `React.memo` 避免不必要的重渲染
- 使用 `useMemo` 缓存计算结果
- 使用 `useCallback` 缓存回调函数

✅ **类型安全**：
- 所有组件都有完整的 TypeScript 类型定义
- Props 接口清晰明确
- 导出所有类型供外部使用
