## 2. 核心组件

### 2.1 数据层隔离（Row-Level Security）

**文件**: `backend/api/middleware/row_level_security.go`

**核心功能**:
- 自动为所有SELECT/INSERT/UPDATE/DELETE添加租户过滤
- 防止修改`tenant_id`字段
- 验证租户访问权限
- 批量数据完整性检查

**关键接口**:
```go
// GORM插件
type TenantScopePlugin struct {
    SkipCallbackTables map[string]bool      // 跳过的系统表
    TenantIDGetter    func(context.Context) string
}

// 使用示例
db.Use(&TenantScopePlugin{
    TenantIDGetter: GetTenantIDFromContext,
})

// 自动添加租户过滤
db.WithContext(ctx).Find(&bots) // 自动 WHERE tenant_id = ?
```

**安全机制**:
1. SELECT自动添加`WHERE tenant_id = ?`
2. INSERT自动设置`tenant_id`字段
3. UPDATE阻止修改`tenant_id`字段
4. DELETE自动添加`WHERE tenant_id = ?`

### 2.2 缓存层隔离

**文件**: `backend/infra/cache/tenant_isolated_cache.go`

**Redis Key格式**:
- String: `tenant:{tenant_id}:{key}`
- Hash: `tenant:{tenant_id}:hash:{key}`
- List: `tenant:{tenant_id}:list:{key}`

**核心功能**:
- 自动添加租户前缀
- 支持批量操作（MGet/MSet/MDel）
- 缓存统计（命中率、操作计数）
- 租户级缓存清理

**关键接口**:
```go
type TenantIsolatedCache struct {
    redis      cache.Cmdable
    EnableStats bool
    Stats      *CacheStats
}

// 使用示例
cache := NewTenantIsolatedCache(redisClient)

// 自动添加租户前缀
cache.Get(ctx, tenantID, "user:123", &user)
cache.Set(ctx, tenantID, "user:123", user, 5*time.Minute)

// 批量操作
cache.MGet(ctx, tenantID, []string{"user:1", "user:2"})
cache.MSet(ctx, tenantID, data, ttl)
```

### 2.6 租户限流中间件

**文件**: `backend/api/middleware/tenant_rate_limiter.go`

**核心功能**:
- 基于Token Bucket算法的速率限制
- 并发数限制（可选）
- 分布式限流（基于Redis）
- 动态配置
- 统计监控

**使用示例**:
```go
// 创建限流器
config := &RateLimitConfig{
    Rate:                  100,  // 每秒100个请求
    Burst:                 200,  // 突发容量200
    EnableConcurrencyLimit: true,
    MaxConcurrency:        100,  // 最大并发100
}
limiter := NewTenantRateLimiter(redisClient, config)

// 应用中间件
app.Use(limiter.Middleware())

// 动态调整租户配置
limiter.SetTenantConfig(tenantID, &RateLimitConfig{
    Rate:  200,
    Burst: 400,
})
```

## 7. 使用示例

### 7.1 完整的租户数据访问流程

```go
// 1. 创建Bot（自动注入tenant_id）
func (s *BotService) CreateBot(ctx context.Context, req *CreateBotRequest) (*Bot, error) {
    tenantID := middleware.GetTenantIDFromContext(ctx)

    bot := &Bot{
        BotID:   generateID(),
        Name:    req.Name,
        // TenantID会被GORM插件自动注入
    }

    if err := s.db.WithContext(ctx).Create(bot).Error; err != nil {
        return nil, err
    }

    // 缓存Bot信息
    s.cache.Set(ctx, tenantID, fmt.Sprintf("bot:%s", bot.BotID), bot, 5*time.Minute)

    // 索引到Elasticsearch
    s.search.IndexDocument(ctx, tenantID, "bots", bot.BotID, bot)

    return bot, nil
}

// 2. 查询Bot（自动添加租户过滤）
func (s *BotService) GetBot(ctx context.Context, botID string) (*Bot, error) {
    var bot Bot

    // 自动添加 WHERE tenant_id = ?
    if err := s.db.WithContext(ctx).Where("bot_id = ?", botID).First(&bot).Error; err != nil {
        return nil, err
    }

    return &bot, nil
}

// 3. 批量操作（验证数据完整性）
func (s *BotService) BatchUpdateBots(ctx context.Context, updates []*BotUpdate) error {
    // 验证所有Bot属于同一租户
    bots := make([]Bot, len(updates))
    for i, update := range updates {
        bots[i] = Bot{BotID: update.BotID, TenantID: update.TenantID}
    }

    if err := middleware.EnsureTenantDataIntegrity(ctx, bots); err != nil {
        return err
    }

    // 批量更新
    return s.db.WithContext(ctx).Transaction(func(tx *gorm.DB) error {
        for _, update := range updates {
            if err := tx.Model(&Bot{}).Where("bot_id = ?", update.BotID).Updates(update).Error; err != nil {
                return err
            }
        }
        return nil
    })
}
```

### 7.2 租户清理流程

```go
// 删除租户时清理所有数据
func (s *TenantService) DeleteTenant(ctx context.Context, tenantID string) error {
    // 1. 清理数据库（GORM插件会自动过滤）
    if err := s.db.Where("tenant_id = ?", tenantID).Delete(&Bot{}).Error; err != nil {
        return err
    }
    // ... 删除其他表数据

    // 2. 清理缓存
    s.cache.ClearTenant(ctx, tenantID)

    // 3. 清理搜索索引
    s.search.ClearTenantIndex(ctx, tenantID)

    // 4. 清理对象存储
    count, size, err := s.storage.ClearTenantBucket(ctx, tenantID)
    if err != nil {
        logs.CtxWarnf(ctx, "failed to clear storage: %v", err)
    }

    logs.CtxInfof(ctx, "tenant cleaned: id=%s, files=%d, size=%d", tenantID, count, size)

    return nil
}
```

## 8. 已知限制

### 8.1 技术限制

1. **Raw SQL绕过风险**
   - 使用`db.Raw()`执行的SQL不会自动添加租户过滤
   - **解决方案**: 禁止使用Raw SQL，或手动添加租户过滤

2. **分布式事务**
   - 跨服务的租户一致性需要额外的协调机制
   - **解决方案**: 使用Saga模式或事件驱动架构

3. **历史数据迁移**
   - 现有数据需要批量添加`tenant_id`字段
   - **解决方案**: 使用数据迁移工具（见数据迁移方案）

### 8.2 性能限制

1. **缓存淘汰**
   - Redis内存有限，大量租户可能导致缓存淘汰
   - **解决方案**: 为不同租户设置不同的TTL

2. **索引数量**
   - 每个租户独立索引，可能导致索引数量过多
   - **解决方案**: 使用索引模板、定期清理
