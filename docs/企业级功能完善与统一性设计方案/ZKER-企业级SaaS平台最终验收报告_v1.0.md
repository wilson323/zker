## 🚀 核心技术优势

### 1. DDD四层架构（领域驱动设计）

```
┌─────────────────────────────────────┐
│         API Layer (Handler)         │  ← HTTP请求处理
├─────────────────────────────────────┤
│      Application Layer (Service)    │  ← 用例编排、事务边界
├─────────────────────────────────────┤
│         Domain Layer (Core)         │  ← 核心业务逻辑（Entity + Repository）
├─────────────────────────────────────┤
│      Infrastructure Layer (Infra)    │  ← 技术实现（DB、Cache、MQ）
└─────────────────────────────────────┘
```

**优势**：
- ✅ **领域隔离**：业务逻辑与技术实现分离
- ✅ **依赖倒置**：domain层不依赖任何外层
- ✅ **易于测试**：每层可独立测试
- ✅ **灵活扩展**：新增功能不影响现有代码

### 2. Saga分布式事务（独创功能）

```go

- ✅ **事务监控**：完整的事务执行日志
- ✅ **一致性保证**：确保跨服务数据一致

# 1. 启动Docker Desktop（Windows）

docker compose ps

# 预期输出：
# ✅ zker-mysql          Up    0.0.0.0:3306->3306/tcp
# ✅ zker-redis          Up    0.0.0.0:6379->6379/tcp
# ✅ zker-elasticsearch  Up    0.0.0.0:9200->9200/tcp
# ✅ zker-prometheus     Up    0.0.0.0:9090->9090/tcp
# ✅ zker-grafana        Up    0.0.0.0:3000->3000/tcp
```

```bash
# 1. 初始化数据库
cd D:\code\coze-studio
make sql_init

# 2. 启动Go后端（开发模式）
make server

# 或生产模式
cd backend
go build -o zker-api ./cmd/api
./zker-api --config conf/config.prod.toml
```

```bash

```
