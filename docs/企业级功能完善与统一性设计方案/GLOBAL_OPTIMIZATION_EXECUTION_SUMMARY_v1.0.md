## 📐 架构与规范

### 核心原则

**SOLID原则**:
- ✅ **S**ingle Responsibility - 单一职责
- ✅ **O**pen/Closed - 开放封闭
- ✅ **L**iskov Substitution - 里氏替换
- ✅ **I**nterface Segregation - 接口隔离
- ✅ **D**ependency Inversion - 依赖倒置

**其他原则**:
- ✅ **KISS** - Keep It Simple, Stupid
- ✅ **DRY** - Don't Repeat Yourself
- ✅ **YAGNI** - You Aren't Gonna Need It

---

### 代码规范

**命名规范**:
- 组件: PascalCase（InvoiceManagement）
- 文件: PascalCase（InvoiceManagement.tsx）
- 变量/函数: camelCase（invoiceList）
- 常量: UPPER_SNAKE_CASE（MAX_PAGE_SIZE）
- 接口: I前缀或PascalCase（IInvoiceService）

**目录结构**:
```
frontend/packages/studio/src/pages/billing/InvoiceManagement/
├── InvoiceManagement.tsx          # 页面入口
├── components/                    # 页面组件
├── hooks/                         # 页面hooks
├── types/                         # 类型定义
├── constants/                     # 常量
├── utils/                         # 工具函数
├── __tests__/                     # 测试
├── index.ts                       # 导出
└── styles.module.less             # 样式
```
