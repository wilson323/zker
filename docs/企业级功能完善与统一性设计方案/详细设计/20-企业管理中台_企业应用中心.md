## 1. 模块概述

**企业应用中心** 通过**应用上架 + 应用分发 + 应用管理**，为企业提供统一的应用入口和管理能力。

**核心设计理念**：
- ✅ **应用商店**：企业内部应用商店
- ✅ **统一入口**：单点登录(SSO)
- ✅ **应用管理**：应用生命周期管理

**实现策略**：✅ 30% 编码（应用框架） + 70% 配置（应用数据）

---

## 2. 核心功能

### 2.1 应用管理

**F1 - 应用上架**：管理员上传应用
**F2 - 应用分发**：用户安装/卸载应用
**F3 - 应用监控**：应用使用统计

---

## 3. 数据库设计

### 3.1 核心表结构

```sql
CREATE TABLE enterprise_apps (
    id VARCHAR(64) PRIMARY KEY,
    tenant_id VARCHAR(64) NOT NULL,
    name VARCHAR(100) NOT NULL,
    icon VARCHAR(512),
    description VARCHAR(500),
    app_url VARCHAR(512) NOT NULL COMMENT '应用URL',
    sso_enabled BOOLEAN DEFAULT FALSE COMMENT '是否启用SSO',

    is_active BOOLEAN DEFAULT TRUE,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,

    INDEX idx_tenant_id (tenant_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE user_app_installations (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    tenant_id VARCHAR(64) NOT NULL,
    user_id BIGINT NOT NULL,
    app_id VARCHAR(64) NOT NULL,

    installed_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    last_accessed_at DATETIME,

    UNIQUE KEY uk_user_app (user_id, app_id),
    INDEX idx_tenant_user (tenant_id, user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## 4. API设计

| 方法 | 路径 | 功能 |
|------|------|------|
| GET | /api/v1/apps | 列出应用 |
| POST | /api/v1/apps | 创建应用 |
| POST | /api/v1/apps/:id/install | 安装应用 |
| DELETE | /api/v1/apps/:id/uninstall | 卸载应用 |
