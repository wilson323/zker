## 新增功能

### Agent 应用级监控

**指标**:
- QPS（每秒请求数）
- 响应时间（P50、P95、P99）
- Token消耗
- 错误率
- 用户满意度

**告警规则**:
- QPS < 阈值（服务降级）
- 响应时间 > 阈值（性能告警）
- 错误率 > 阈值（紧急告警）
