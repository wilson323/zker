## 1. 模块概述

### 1.1 模块定位

**技能资源管理** 是 ZKER 企业级 SaaS 平台企业管理中台的核心模块，通过**完全复用 zker Plugin 系统 + 数据库配置映射**的方式，为企业提供技能资源的管理、编排、授权能力。

**核心设计理念**：
- ✅ **零编码复用**：100% 复用 zker Plugin 系统，无需额外开发
- ✅ **概念映射**：Plugin → 技能，Workflow → 技能编排
- ✅ **数据驱动**：通过数据库配置实现技能分类、标签、授权
- ✅ **低代码编排**：可视化界面编排技能，无需编码

### 1.2 与 zker Plugin 系统的关系

```
┌─────────────────────────────────────────────────────────────────┐
│                    鲸智百应 - 技能资源管理                        │
├─────────────────────────────────────────────────────────────────┤
│  技能商店  │  技能编排  │  技能授权  │  技能监控  │  技能评价    │
└────────────────┬────────────────────────────────────────────────┘
                 ↓ 映射关系
┌─────────────────────────────────────────────────────────────────┐
│                    zker - Plugin 系统                           │
├─────────────────────────────────────────────────────────────────┤
│  Plugin Store │ Workflow │ RBAC │ Metrics │ Reviews/Ratings    │
└─────────────────────────────────────────────────────────────────┘
```

| 鲸智百应概念 | zker 概念 | 实现方式 |
|-------------|-----------|----------|
| 技能 (Skill) | Plugin (插件) | 直接映射 |

### 3.2 核心流程

#### 3.2.1 技能商店浏览流程

```
用户访问技能商店
        ↓
调用 SkillManagementService.ListSkills()
        ↓
内部调用 PluginService.ListPlugins()
        ↓
应用企业技能分类过滤 (FROM skill_categories WHERE tenant_id = ?)
        ↓
应用技能授权过滤 (仅显示当前用户有权限的技能)
        ↓
返回技能列表 (包含使用量、评分、分类等信息)
        ↓
前端展示技能商店页面
```

#### 3.2.2 技能授权流程

```
企业管理员授权技能给角色
        ↓
调用 SkillManagementService.GrantSkillPermission(roleId, skillId)
        ↓
在 role_permissions 表中插入记录
  INSERT INTO role_permissions (role_id, resource_type, resource_id, permissions)
  VALUES (roleId, 'skill', skillId, ['use', 'config'])
        ↓
权限立即生效
        ↓
该角色下的所有用户自动获得技能访问权限
```

#### 3.2.3 技能编排流程

```
用户打开技能编排器
        ↓
拖拽技能节点到画布
        ↓
配置节点参数（输入变量、输出变量）
        ↓
连接节点，定义数据流
        ↓
点击"调试"执行编排
        ↓
WorkflowService.ExecuteWorkflow()
        ↓
实时返回执行结果
        ↓
保存编排（版本管理）
```

## 4. 数据库设计

### 4.1 复用 zker 表结构

**核心设计**：100% 复用 zker Plugin 系统表，通过新增映射表实现"技能"概念。

#### 4.1.1 直接复用的表

| 表名 | 用途 | 备注 |
|------|------|------|
| `plugins` | 技能定义 | 直接映射 Plugin → Skill |
| `plugin_tags` | 技能标签 | 直接复用 |
| `plugin_reviews` | 技能评价 | 直接复用 |
| `plugin_metrics` | 技能使用统计 | 直接复用 |
| `workflows` | 技能编排 | 直接复用 |
| `workflow_nodes` | 编排节点 | 直接复用 |
| `workflow_executions` | 编排执行记录 | 直接复用 |

#### 4.1.2 新增映射表

**表1: 企业技能分类表 (skill_categories)**

用于企业管理员自定义技能分类，与 zker Plugin Tags 形成映射。

```sql
CREATE TABLE skill_categories (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '分类ID',
    tenant_id VARCHAR(64) NOT NULL COMMENT '租户ID',
    parent_id BIGINT DEFAULT NULL COMMENT '父分类ID',
    name VARCHAR(100) NOT NULL COMMENT '分类名称',
    description VARCHAR(500) COMMENT '分类描述',
    icon VARCHAR(512) COMMENT '分类图标URL',
    sort_order INT DEFAULT 0 COMMENT '排序',
    is_active BOOLEAN DEFAULT TRUE COMMENT '是否启用',
    created_by BIGINT COMMENT '创建者ID',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    deleted_at DATETIME DEFAULT NULL,

    UNIQUE KEY uk_tenant_name (tenant_id, name),
    INDEX idx_tenant_id (tenant_id),
    INDEX idx_parent_id (parent_id),
    INDEX idx_deleted_at (deleted_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
COMMENT='企业技能分类表';
```

**表2: 技能授权表 (skill_permissions)**

用于记录技能授权给角色/用户的权限。

```sql
CREATE TABLE skill_permissions (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '授权ID',
    tenant_id VARCHAR(64) NOT NULL COMMENT '租户ID',
    skill_id VARCHAR(64) NOT NULL COMMENT '技能ID (对应 plugins.id)',
    grantee_type ENUM('role', 'user') NOT NULL COMMENT '被授权者类型',
    grantee_id VARCHAR(64) NOT NULL COMMENT '被授权者ID (role_id 或 user_id)',
    permissions JSON NOT NULL COMMENT '权限列表 ["use", "config", "manage"]',
    granted_by BIGINT NOT NULL COMMENT '授权者ID',
    granted_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    expires_at DATETIME DEFAULT NULL COMMENT '过期时间 (NULL表示永久)',
    is_active BOOLEAN DEFAULT TRUE COMMENT '是否生效',

    UNIQUE KEY uk_skill_grantee (skill_id, grantee_type, grantee_id),
    INDEX idx_tenant_id (tenant_id),
    INDEX idx_skill_id (skill_id),
    INDEX idx_grantee (grantee_type, grantee_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
COMMENT='技能授权表';
```

**表3: 技能分类关联表 (skill_category_mappings)**

用于关联技能与分类（多对多关系）。

```sql
CREATE TABLE skill_category_mappings (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '映射ID',
    tenant_id VARCHAR(64) NOT NULL COMMENT '租户ID',
    skill_id VARCHAR(64) NOT NULL COMMENT '技能ID',
    category_id BIGINT NOT NULL COMMENT '分类ID',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,

    UNIQUE KEY uk_skill_category (skill_id, category_id),
    INDEX idx_tenant_id (tenant_id),
    INDEX idx_category_id (category_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
COMMENT='技能分类关联表';
```

// ListStoreSkills 列出技能商店中的技能
func (s *SkillManagementService) ListStoreSkills(
    ctx context.Context,
    req *ListStoreSkillsRequest,
) (*ListStoreSkillsResponse, error) {
    // 1. 调用 zker Plugin Service
    pluginReq := &plugin.ListPluginsRequest{
        Type:       req.Type,
        Tags:       req.Tags,
        Search:     req.Search,
        IsPublic:   true, // 仅显示公开技能
        Page:       req.Page,
        PageSize:   req.PageSize,
    }

    pluginResp, err := s.pluginService.ListPlugins(ctx, pluginReq)
    if err != nil {
        return nil, err
    }

    // 2. 补充企业分类信息
    skills := make([]*StoreSkillItem, 0, len(pluginResp.Items))
    for _, p := range pluginResp.Items {
        // 查询技能的企业分类
        categoryID, err := s.categoryRepo.GetSkillCategoryID(ctx, p.ID)
        if err != nil {
            s.logger.Warn("failed to get skill category", zap.String("skill_id", p.ID))
            categoryID = nil
        }

        // 检查当前用户是否有权限
        hasPermission, err := s.permissionRepo.CheckUserPermission(
            ctx, getUserID(ctx), p.ID, "use",
        )

        skills = append(skills, &StoreSkillItem{
            Plugin:         p,
            CategoryID:     categoryID,
            HasPermission:  hasPermission,
            Installed:      s.isInstalled(ctx, p.ID),
        })
    }

    return &ListStoreSkillsResponse{
        Items:    skills,
        Total:    pluginResp.Total,
        Page:     req.Page,
        PageSize: req.PageSize,
    }, nil
}

func (s *SkillManagementService) GrantSkillPermission(
    ctx context.Context,
    req *GrantPermissionRequest,
) (*GrantPermissionResponse, error) {
    // 1. 验证技能是否存在
    _, err := s.pluginService.GetPlugin(ctx, req.SkillID)
    if err != nil {
        return nil, fmt.Errorf("skill not found: %w", err)
    }

    // 2. 验证被授权者是否存在
    if req.GranteeType == "role" {
        _, err = s.roleService.GetRole(ctx, req.GranteeID)
        if err != nil {
            return nil, fmt.Errorf("role not found: %w", err)
        }
    } else {
        _, err = s.userService.GetUser(ctx, req.GranteeID)
        if err != nil {
            return nil, fmt.Errorf("user not found: %w", err)
        }
    }

    // 3. 检查是否已经授权
    existing, err := s.permissionRepo.GetPermission(
        ctx, req.SkillID, req.GranteeType, req.GranteeID,
    )
    if err == nil && existing != nil {
        return nil, errors.New("permission already granted")
    }

    // 4. 创建授权记录
    permission := &model.SkillPermission{
        TenantID:     getTenantID(ctx),
        SkillID:      req.SkillID,
        GranteeType:  req.GranteeType,
        GranteeID:    req.GranteeID,
        Permissions:  req.Permissions,
        GrantedBy:    getUserID(ctx),
        ExpiresAt:    req.ExpiresAt,
        IsActive:     true,
    }

    if err := s.permissionRepo.Create(ctx, permission); err != nil {
        return nil, err
    }

    // 5. 清除相关缓存
    s.clearPermissionCache(ctx, req.GranteeType, req.GranteeID)

    return &GrantPermissionResponse{
        ID:          permission.ID,
        SkillID:     permission.SkillID,
        GranteeType: permission.GranteeType,
        GranteeID:   permission.GranteeID,
        Permissions: permission.Permissions,
        GrantedAt:   permission.GrantedAt,

func (s *SkillManagementService) ListStoreSkills(
	ctx context.Context,

	for _, p := range pluginResp.Items {
		// 查询企业分类
		categoryID, err := s.categoryRepo.GetSkillCategoryID(ctx, p.ID)
		if err != nil {
			s.logger.Warn("failed to get skill category", zap.String("skill_id", p.ID))
		}

		// 检查用户权限
		hasPermission := s.checkUserPermission(ctx, getUserID(ctx), p.ID)

		skills = append(skills, &StoreSkill{
			ID:          p.ID,
			Name:        p.Name,
			Description: p.Description,
			Type:        p.Type,
			Icon:        p.Icon,
			CategoryID:  categoryID,
			Tags:        p.Tags,
			Publisher:   p.Publisher,
			Version:     p.Version,
			Stats: SkillStats{
				InstallCount: p.InstallCount,
				UseCount:     p.UseCount,
				AvgRating:    p.AvgRating,
			},
			HasPermission: hasPermission,
			Installed:     s.isInstalled(ctx, p.ID),
		})
	}

	return &ListStoreSkillsResponse{
		Items:    skills,
		Total:    pluginResp.Total,
		Page:     req.Page,
		PageSize: req.PageSize,
	}, nil
}

// GrantSkillPermission 授权技能给角色/用户
// 实现方式：INSERT INTO skill_permissions
func (s *SkillManagementService) GrantSkillPermission(
	ctx context.Context,
	req *GrantPermissionRequest,
) (*GrantPermissionResponse, error) {
	// 1. 验证技能存在
	_, err := s.pluginService.GetPlugin(ctx, req.SkillID)
	if err != nil {
		return nil, fmt.Errorf("skill not found: %w", err)
	}

	// 2. 创建授权记录
	permission := &model.SkillPermission{
		TenantID:    getTenantID(ctx),
		SkillID:     req.SkillID,
		GranteeType: req.GranteeType,
		GranteeID:   req.GranteeID,
		Permissions: req.Permissions,
		GrantedBy:   getUserID(ctx),
		ExpiresAt:   req.ExpiresAt,
		IsActive:    true,
	}

	if err := s.permissionRepo.Create(ctx, permission); err != nil {
		return nil, fmt.Errorf("failed to grant permission: %w", err)
	}

	// 3. 清除缓存
	s.clearPermissionCache(ctx, req.GranteeType, req.GranteeID)

	return &GrantPermissionResponse{
		ID:          permission.ID,
		SkillID:     permission.SkillID,
		GranteeType: permission.GranteeType,
		GranteeID:   permission.GranteeID,
		Permissions: permission.Permissions,
		GrantedAt:   permission.GrantedAt,
		ExpiresAt:   permission.ExpiresAt,
	}, nil
}

// GetSkillUsageStats 获取技能使用统计
// 实现方式：100%复用 MetricsService.GetPluginMetrics()
func (s *SkillManagementService) GetSkillUsageStats(
	ctx context.Context,
	skillID string,
	startDate, endDate time.Time,
) (*SkillUsageStats, error) {
	// 1. 调用 zker Metrics Service
	metricsReq := &metrics.GetPluginMetricsRequest{

	}

	pluginMetrics, err := s.metricsService.GetPluginMetrics(ctx, metricsReq)

		SkillName: pluginMetrics.PluginName,
		Period: Period{
			StartDate: startDate,
			EndDate:   endDate,
		},
		Usage: Usage{
			TotalCalls:   pluginMetrics.TotalCalls,
			SuccessCalls: pluginMetrics.SuccessCalls,
			FailedCalls:  pluginMetrics.FailedCalls,
			SuccessRate:  float64(pluginMetrics.SuccessCalls) / float64(pluginMetrics.TotalCalls),
		},
		Users: Users{
			TotalUsers:  pluginMetrics.TotalUsers,
			ActiveUsers: pluginMetrics.ActiveUsers,
		},
		Performance: Performance{
			AvgLatency: pluginMetrics.AvgLatency,
			P50Latency: pluginMetrics.P50Latency,
			P95Latency: pluginMetrics.P95Latency,
			P99Latency: pluginMetrics.P99Latency,
		},
		Errors: s.aggregateErrors(pluginMetrics.Errors),
	}, nil
}

// checkUserPermission 检查用户是否有技能权限
func (s *SkillManagementService) checkUserPermission(
	ctx context.Context,
	userID int64,
	skillID string,
) bool {
	// 1. 检查直接授权
	directPermission, err := s.permissionRepo.GetPermissionByUser(ctx, userID, skillID)
	if err == nil && directPermission != nil {
		return true
	}

	// 2. 检查角色权限
	userRoles, err := s.roleService.GetUserRoles(ctx, userID)
	if err == nil {
		for _, role := range userRoles {
			rolePermission, err := s.permissionRepo.GetPermissionByRole(ctx, role.ID, skillID)
			if err == nil && rolePermission != nil {
				return true
			}
		}
	}

	return false
}

// isInstalled 检查技能是否已安装
func (s *SkillManagementService) isInstalled(ctx context.Context, skillID string) bool {
	tenantID := getTenantID(ctx)
	installed, _ := s.pluginService.CheckPluginInstalled(ctx, tenantID, skillID)
	return installed
}
