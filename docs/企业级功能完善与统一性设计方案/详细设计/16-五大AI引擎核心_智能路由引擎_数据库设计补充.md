## 2. 核心业务表

### 2.1 路由规则表 (routing_rules)

**用途**: 存储管理员自定义的路由规则

```sql
CREATE TABLE routing_rules (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '规则ID',
    tenant_id VARCHAR(64) NOT NULL COMMENT '租户ID',
    name VARCHAR(100) NOT NULL COMMENT '规则名称',
    description VARCHAR(500) COMMENT '规则描述',

    -- 优先级
    priority INT NOT NULL DEFAULT 0 COMMENT '优先级 (数字越小越高)',
    is_active BOOLEAN DEFAULT TRUE COMMENT '是否启用',

    -- 触发条件
    condition JSON NOT NULL COMMENT '触发条件 {
  "intent": ["knowledge_query", "task_execution"],
  "keywords": ["价格", "创建", "订单"],
  "user_roles": ["admin", "sales"],
  "departments": ["销售部"],
  "time_range": {
    "start": "09:00",
    "end": "18:00"
  }
}',

    -- 路由动作
    action JSON NOT NULL COMMENT '路由动作 {
  "target_service_id": "bot-001",
  "filter_type": "department",
  "filter_value": "销售部",
  "priority_adjustment": 10
}',

    -- 统计
    match_count INT DEFAULT 0 COMMENT '匹配次数',
    last_matched_at DATETIME COMMENT '最后匹配时间',

    -- 审计
    created_by BIGINT COMMENT '创建者ID',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    updated_by BIGINT COMMENT '更新者ID',
    deleted_at DATETIME DEFAULT NULL,

    UNIQUE KEY uk_tenant_name (tenant_id, name),
    INDEX idx_tenant_id (tenant_id),
    INDEX idx_priority (priority),
    INDEX idx_is_active (is_active),
    INDEX idx_deleted_at (deleted_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
COMMENT='路由规则表';
```

**字段说明**:
- `priority`: 规则优先级,数字越小优先级越高
- `condition`: JSON格式,支持意图、关键词、用户角色、部门、时间范围等条件
- `action`: JSON格式,指定目标服务、筛选类型、优先级调整等

### 2.2 路由决策表 (routing_decisions)

**用途**: 记录每次路由决策的详细信息

```sql
CREATE TABLE routing_decisions (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '决策ID',
    tenant_id VARCHAR(64) NOT NULL COMMENT '租户ID',
    user_id BIGINT NOT NULL COMMENT '用户ID',
    session_id VARCHAR(64) NOT NULL COMMENT '会话ID',

    -- 输入信息
    user_input TEXT NOT NULL COMMENT '用户输入',
    preprocessed_input TEXT COMMENT '预处理后的输入',

    -- 意图识别结果
    intent_id VARCHAR(64) COMMENT '意图ID',
    intent_type VARCHAR(50) NOT NULL COMMENT '意图类型',
    intent_confidence DECIMAL(5,4) NOT NULL COMMENT '意图置信度',
    entities JSON COMMENT '提取的实体 {
  "person": "张三",
  "product": "XX产品",
  "time": "上个月"
}',

    -- 候选服务
    candidates JSON COMMENT '候选服务列表 [
  {
    "service_id": "bot-001",
    "service_name": "产品问答Bot",
    "score": 0.85,
    "reasons": ["用户匹配度: 0.80", "历史成功率: 0.90"]
  }
]',

    -- 选中的服务
    selected_service_id VARCHAR(64) NOT NULL COMMENT '选中的服务ID',
    selected_service_name VARCHAR(100) NOT NULL COMMENT '选中的服务名称',
    decision_confidence DECIMAL(5,4) NOT NULL COMMENT '决策置信度',

    -- 决策理由
    decision_reason TEXT COMMENT '决策理由 (可解释性)',

    -- 性能指标
    decision_time_ms INT NOT NULL COMMENT '决策耗时 (毫秒)',

    -- 匹配的规则
    matched_rule_id BIGINT COMMENT '匹配的规则ID',

    -- 时间
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP COMMENT '决策时间',

    INDEX idx_tenant_user (tenant_id, user_id),
    INDEX idx_session_id (session_id),
    INDEX idx_intent_type (intent_type),
    INDEX idx_selected_service (selected_service_id),
    INDEX idx_created_at (created_at),
    INDEX idx_decision_time_ms (decision_time_ms)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
COMMENT='路由决策表';
```

**字段说明**:
- `entities`: JSON格式,存储NLP提取的实体(人名、产品名、时间等)
- `candidates`: JSON格式,记录所有候选服务及其评分
- `decision_reason`: 可解释性,说明为什么选择该服务
