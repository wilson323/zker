## 1. 模块概述

**写作模板管理** 是 ZKER 企业级 SaaS 平台的企业管理中台模块，通过**通用CRUD框架 + 数据库模板配置**的方式，提供写作模板管理能力。

**核心设计理念**：
- ✅ **零编码复用**：100% 复用通用CRUD框架
- ✅ **数据驱动**：所有模板通过数据库配置
- ✅ **企业定制**：企业可自定义写作模板

**实现策略**：✅ 0% 编码 + 100% 配置（复用CRUD框架）

## 4. API 设计

**复用通用CRUD框架**，仅需定义路由：

| 方法 | 路径 | 功能 | 实现方式 |
|------|------|------|----------|
| GET | /api/v1/admin/templates | 列出模板 | 通用CRUD |
| POST | /api/v1/admin/templates | 创建模板 | 通用CRUD |
| PUT | /api/v1/admin/templates/:id | 更新模板 | 通用CRUD |
| DELETE | /api/v1/admin/templates/:id | 删除模板 | 通用CRUD |
| GET | /api/v1/admin/template-categories | 列出分类 | 通用CRUD |

**Go 代码示例**（复用CRUD框架）：

```go
package admin

// TemplateManagementController 模板管理控制器
type TemplateManagementController struct {
    crudFramework *crud.CrudFramework
}

// RegisterRoutes 注册路由（复用CRUD框架）
func (c *TemplateManagementController) RegisterRoutes(r *路由组) {
    // 复用通用CRUD处理器
    r.GET("/templates", c.crudFramework.List(&WritingTemplate{}))
    r.POST("/templates", c.crudFramework.Create(&WritingTemplate{}))
    r.PUT("/templates/:id", c.crudFramework.Update(&WritingTemplate{}))
    r.DELETE("/templates/:id", c.crudFramework.Delete(&WritingTemplate{}))
}
```
