## 1. 模块概述

**WorkflowEditor** 是 ZKER 的可视化工作流编辑器，通过**100%复用zker Workflow系统**，实现复杂业务流程的可视化编排。

**核心设计理念**：
- ✅ **可视化编排**：拖拽式节点编辑
- ✅ **低代码开发**：无需编程即可构建复杂流程
- ✅ **调试执行**：可视化调试和执行日志

**实现策略**：✅ 100%复用zker Workflow系统

---

## 2. 核心功能（完全复用）

### 2.1 流程编辑

**F1 - 可视化画布**（复用）
- F1.1 拖拽节点
- F1.2 连接节点
- F1.3 配置节点参数

### 2.2 节点类型（复用）

**F2 - 预置节点**（复用）
- F2.1 触发器节点（HTTP、定时器）
- F2.2 技能节点（Bot、插件）
- F2.3 逻辑节点（条件、循环）
- F2.4 数据节点（数据库、API）

### 2.3 调试执行（复用）

**F3 - 流程测试**（复用）
- F3.1 单步调试
- F3.2 断点调试
- F3.3 执行日志

---

## 3. 数据库设计（完全复用）

**完全复用 zker Workflow 系统的表**：
- `workflows`：工作流定义
- `workflow_nodes`：节点定义
- `workflow_executions`：执行记录

---

## 4. API设计（完全复用）

| 方法 | 路径 | 功能 | 实现方式 |
|------|------|------|----------|
| GET | /api/v1/workflows | 列出工作流 | → zker |
| POST | /api/v1/workflows | 创建工作流 | → zker |
| PUT | /api/v1/workflows/:id | 更新工作流 | → zker |
| POST | /api/v1/workflows/:id/execute | 执行工作流 | → zker |
| GET | /api/v1/workflows/:id/executions | 查看执行记录 | → zker |
