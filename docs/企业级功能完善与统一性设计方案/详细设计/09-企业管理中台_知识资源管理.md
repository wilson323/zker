## 1. 模块概述

### 1.1 模块定位

**知识资源管理** 是 ZKER 企业级 SaaS 平台企业管理中台的核心模块，通过**可扩展文档处理框架 + 解析器配置**的方式，为企业提供多格式知识库管理、智能问答、语义检索能力。

**核心设计理念**：
- ✅ **框架可扩展**：30% 核心框架 + 70% 解析器配置
- ✅ **格式广泛**：支持 PDF、Word、Excel、PPT、TXT、Markdown、HTML 等
- ✅ **智能分块**：支持多种分块策略（固定长度、语义、章节）
- ✅ **语义检索**：基于 Milvus 向量数据库的语义搜索
- ✅ **企业级**：多租户隔离、权限控制、审计日志

### 1.2 业务价值

| 受益者 | 价值 |
|--------|------|
| **企业用户** | 一站式管理企业知识，快速上传多格式文档，智能问答提升效率 |
| **企业管理员** | 统一管理企业知识资产，控制知识访问权限，监控知识使用情况 |
| **AI 应用** | Bot 可关联知识库，实现基于企业知识的专业问答 |

### 1.3 与鲸智百应功能对齐

| 鲸智百应功能 | ZKER 实现方式 | 实现策略 |
|-------------|--------------|----------|
| 知识库管理（创建、编辑、删除） | ✅ knowledge_bases 表 | 数据库 CRUD |
| 文档上传（多格式支持） | ✅ 可扩展文档处理框架 | 30% 框架 + 配置化解析器 |
| 文档解析（文本、表格、图片） | ✅ Parser 配置 + Extractor | 70% 配置驱动 |
| 知识分块（智能分块策略） | ✅ Chunker 配置 | 数据库配置分块策略 |
| 向量化存储（Milvus） | ✅ Vector Store | zker 已集成 |
| 知识问答（RAG） | ✅ RAG Pipeline | zker 已实现 |
| 知识权限（RBAC） | ✅ knowledge_permissions 表 | 数据库配置 |
| 知识统计（使用量、命中率） | ✅ knowledge_metrics 表 | 数据库统计 |

**实现策略**：✅ 30% 编码（可扩展框架） + 70% 配置（解析器、分块策略）

## 2. 功能需求

- F2.4 查看文档详情（解析状态、分块数、向量数）

**F5 - 解析器管理（高级功能）**

### 3.2 核心流程

#### 3.2.1 文档上传与处理流程

```
用户上传文档
        ↓
验证文件格式（从 document_parsers 查询支持的格式）
        ↓
存储文件到 MinIO
        ↓
创建文档记录（documents 表，status = 'pending'）
        ↓
异步任务：解析文档
  ├─ 选择解析器（根据文件扩展名）
  ├─ 提取文本内容（PDF/Word/Excel 等）
  ├─ 提取表格（如果配置）
  ├─ 提取图片（如果配置）
  └─ 保存原始文本（documents.raw_content）
        ↓
分块文档（根据知识库分块策略配置）
  ├─ 加载分块策略（chunk_strategies 表）
  ├─ 执行分块（FixedLength/Semantic/Section）
  └─ 保存分块（document_chunks 表）
        ↓
向量化分块
  ├─ 调用 Embedding 模型
  ├─ 生成向量（768 维）
  └─ 存储到 Milvus
        ↓
更新文档状态（status = 'completed'）
        ↓
发送通知给用户（WebSocket）
```

#### 3.2.2 知识问答流程（RAG）

```
用户提问
        ↓
检查知识库权限（FROM knowledge_permissions）
        ↓
对问题进行向量化
        ↓
Milvus 语义搜索（Top-K 相关分块）
        ↓
构建提示词（系统提示词 + 检索到的知识分块 + 用户问题）
        ↓
调用 LLM 生成回答
        ↓
返回回答 + 引用来源
        ↓
保存问答记录（可选）
```

## 4. 数据库设计

### 4.1 核心表结构

#### 4.1.1 知识库表 (knowledge_bases)

```sql
CREATE TABLE knowledge_bases (
    id VARCHAR(64) PRIMARY KEY COMMENT '知识库ID',
    tenant_id VARCHAR(64) NOT NULL COMMENT '租户ID',
    creator_id BIGINT NOT NULL COMMENT '创建者ID',
    name VARCHAR(100) NOT NULL COMMENT '知识库名称',
    description VARCHAR(500) COMMENT '知识库描述',
    category_id BIGINT COMMENT '分类ID',

    -- 配置
    chunk_strategy_id BIGINT COMMENT '分块策略ID',
    embedding_model VARCHAR(50) DEFAULT 'text-embedding-ada-002' COMMENT '向量化模型',

    -- 统计
    document_count INT DEFAULT 0 COMMENT '文档数量',
    chunk_count INT DEFAULT 0 COMMENT '分块数量',
    total_size BIGINT DEFAULT 0 COMMENT '总大小(字节)',
    question_count INT DEFAULT 0 COMMENT '问答次数',
    hit_rate DECIMAL(5,4) DEFAULT 0.0000 COMMENT '命中率',

    -- 状态
    is_active BOOLEAN DEFAULT TRUE COMMENT '是否启用',

    -- 审计
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    deleted_at DATETIME DEFAULT NULL,

    UNIQUE KEY uk_tenant_name (tenant_id, name),
    INDEX idx_tenant_id (tenant_id),
    INDEX idx_creator_id (creator_id),
    INDEX idx_category_id (category_id),
    INDEX idx_deleted_at (deleted_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
COMMENT='知识库表';
```

#### 4.1.2 文档表 (documents)

```sql
CREATE TABLE documents (
    id VARCHAR(64) PRIMARY KEY COMMENT '文档ID',
    tenant_id VARCHAR(64) NOT NULL COMMENT '租户ID',
    knowledge_base_id VARCHAR(64) NOT NULL COMMENT '知识库ID',
    uploader_id BIGINT NOT NULL COMMENT '上传者ID',

    -- 文件信息
    filename VARCHAR(255) NOT NULL COMMENT '文件名',
    file_type VARCHAR(20) NOT NULL COMMENT '文件类型 (pdf/docx/xlsx/pptx/...)',
    file_size BIGINT NOT NULL COMMENT '文件大小(字节)',
    file_path VARCHAR(512) NOT NULL COMMENT '文件存储路径 (MinIO)',
    file_hash VARCHAR(64) COMMENT '文件哈希 (MD5)',

    -- 解析结果
    raw_content LONGTEXT COMMENT '原始文本内容',
    parsed_content LONGTEXT COMMENT '解析后的文本内容',
    chunk_count INT DEFAULT 0 COMMENT '分块数量',
    vector_count INT DEFAULT 0 COMMENT '向量化数量',

    -- 状态
    status ENUM('pending', 'parsing', 'chunking', 'vectorizing', 'completed', 'failed') DEFAULT 'pending',
    error_message TEXT COMMENT '错误信息',

    -- 统计
    question_count INT DEFAULT 0 COMMENT '被问答次数',
    hit_count INT DEFAULT 0 COMMENT '被命中次数',

    -- 审计
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    deleted_at DATETIME DEFAULT NULL,

    INDEX idx_tenant_kb (tenant_id, knowledge_base_id),
    INDEX idx_uploader_id (uploader_id),
    INDEX idx_status (status),
    INDEX idx_file_type (file_type),
    INDEX idx_deleted_at (deleted_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci
COMMENT='文档表';
```

```go
// UploadDocument 上传文档
func (s *KnowledgeService) UploadDocument(
    ctx context.Context,
    knowledgeBaseID string,
    fileHeader *multipart.FileHeader,
    chunkStrategyID *int64,
) (*UploadDocumentResponse, error) {
    // 1. 验证知识库权限
    if !s.checkPermission(ctx, knowledgeBaseID, "upload") {
        return nil, errors.New("permission denied")
    }

    // 2. 验证文件类型（从 document_parsers 查询）
    fileType := strings.TrimPrefix(filepath.Ext(fileHeader.Filename), ".")
    parser, err := s.parserRepo.GetByFileType(ctx, fileType)
    if err != nil {
        return nil, fmt.Errorf("unsupported file type: %s", fileType)
    }

    // 3. 验证文件大小
    if fileHeader.Size > parser.MaxFileSize {
        return nil, fmt.Errorf("file too large: max %d bytes", parser.MaxFileSize)
    }

    // 4. 存储文件到 MinIO
    filePath := fmt.Sprintf("knowledge/%s/%s", knowledgeBaseID, generateUniqueFilename(fileHeader.Filename))
    reader, err := fileHeader.Open()
    if err != nil {
        return nil, err
    }
    defer reader.Close()

    if err := s.minioClient.UploadFile(ctx, filePath, reader, fileHeader.Size); err != nil {
        return nil, err
    }

    // 5. 创建文档记录
    document := &model.Document{
        ID:              generateDocumentID(),
        TenantID:        getTenantID(ctx),
        KnowledgeBaseID: knowledgeBaseID,
        UploaderID:      getUserID(ctx),
        Filename:        fileHeader.Filename,
        FileType:        fileType,
        FileSize:        fileHeader.Size,
        FilePath:        filePath,
        Status:          "pending",
    }

    if err := s.documentRepo.Create(ctx, document); err != nil {
        return nil, err
    }

    // 6. 异步处理文档（解析、分块、向量化）
    go s.processDocumentAsync(context.Background(), document, parser, chunkStrategyID)

    return &UploadDocumentResponse{
        DocumentID: document.ID,
        Filename:   document.Filename,
        FileSize:   document.FileSize,
        Status:     document.Status,
        CreatedAt:  document.CreatedAt,
    }, nil
}

// processDocumentAsync 异步处理文档
func (s *KnowledgeService) processDocumentAsync(
    ctx context.Context,
    document *model.Document,
    parser *model.DocumentParser,
    chunkStrategyID *int64,
) {
    // 1. 更新状态为解析中
    s.documentRepo.UpdateStatus(ctx, document.ID, "parsing", "")

    // 2. 解析文档（使用可扩展解析器框架）
    parseResult, err := s.parserRegistry.Parse(ctx, document, parser)
    if err != nil {
        s.documentRepo.UpdateStatus(ctx, document.ID, "failed", err.Error())
        return
    }

    // 3. 保存解析结果
    document.RawContent = parseResult.RawContent
    document.ParsedContent = parseResult.ParsedContent
    s.documentRepo.Update(ctx, document)

    // 4. 分块文档
    s.documentRepo.UpdateStatus(ctx, document.ID, "chunking", "")
    chunks, err := s.chunkerRegistry.Chunk(ctx, document, chunkStrategyID)
    if err != nil {
        s.documentRepo.UpdateStatus(ctx, document.ID, "failed", err.Error())
        return
    }

    // 5. 保存分块
    for _, chunk := range chunks {
        s.chunkRepo.Create(ctx, chunk)
    }
    document.ChunkCount = len(chunks)
    s.documentRepo.Update(ctx, document)

    // 6. 向量化
    s.documentRepo.UpdateStatus(ctx, document.ID, "vectorizing", "")
    vectors, err := s.embeddingService.EmbedBatch(ctx, chunks)
    if err != nil {
        s.documentRepo.UpdateStatus(ctx, document.ID, "failed", err.Error())
        return
    }

    // 7. 存储到 Milvus
    for i, chunk := range chunks {
        vectorID, err := s.vectorStore.Store(ctx, vectors[i], chunk.Metadata)
        if err != nil {
            s.logger.Error("failed to store vector", zap.Error(err))
            continue
        }
        chunk.VectorID = vectorID
        s.chunkRepo.Update(ctx, chunk)
    }

    document.VectorCount = len(vectors)
    document.Status = "completed"
    s.documentRepo.Update(ctx, document)

    // 8. 发送通知
    s.notificationService.Send(ctx, document.UploaderID, "文档处理完成", fmt.Sprintf("文档 %s 已成功处理", document.Filename))
}
```

```go
// AskQuestion 知识问答 (RAG)
func (s *KnowledgeService) AskQuestion(
    ctx context.Context,
    knowledgeBaseID string,
    req *AskQuestionRequest,
) (*AskQuestionResponse, error) {
    // 1. 检查知识库权限
    if !s.checkPermission(ctx, knowledgeBaseID, "ask") {
        return nil, errors.New("permission denied")
    }

    // 2. 对问题进行向量化
    questionVector, err := s.embeddingService.Embed(ctx, req.Question)
    if err != nil {
        return nil, err
    }

    // 3. Milvus 语义搜索
    searchResults, err := s.vectorStore.Search(ctx, knowledgeBaseID, questionVector, req.TopK)
    if err != nil {
        return nil, err
    }

    if len(searchResults) == 0 {
        return &AskQuestionResponse{
            Answer:  "抱歉，我在知识库中没有找到相关信息。",
            Sources: []Source{},
        }, nil
    }

    // 4. 加载分块内容
    chunks, err := s.chunkRepo.GetByVectorIDs(ctx, searchResults.VectorIDs())
    if err != nil {
        return nil, err
    }

    // 5. 构建提示词
    contextText := s.buildContext(chunks)
    prompt := s.buildRAGPrompt(req.Question, contextText)

    // 6. 调用 LLM
    llmResp, err := s.llmClient.Chat(ctx, &llm.ChatRequest{
        Model: "gpt-4",
        Messages: []llm.Message{
            {Role: "system", Content: "你是一个专业的知识问答助手，请基于提供的知识库内容回答用户问题。"},
            {Role: "user", Content: prompt},
        },
        Temperature: 0.3,
        MaxTokens:   2000,
    })
    if err != nil {
        return nil, err
    }

    // 7. 构建响应
    sources := make([]Source, 0, len(chunks))
    if req.IncludeSources {
        for i, chunk := range chunks {
            sources = append(sources, Source{
                DocumentID:   chunk.DocumentID,
                DocumentName: chunk.DocumentName,
                ChunkID:      chunk.ID,
                Content:      chunk.Content,
                Score:        searchResults.Scores()[i],
            })
        }
    }

    return &AskQuestionResponse{
        Answer:  llmResp.Content,
        Sources: sources,
    }, nil
}
```

```tsx
import React, { useState } from 'react';
import { Upload, Button, Progress, message } from '@douyinfe/semi-ui';
import { IconUpload } from '@douyinfe/semi-icons';
import { knowledgeAPI } from '@/services/api';

export const KnowledgeBaseUploader: React.FC<{ knowledgeBaseId: string }> = ({ knowledgeBaseId }) => {
  const [uploading, setUploading] = useState(false);
  const [progress, setProgress] = useState(0);

  const handleUpload = async (fileList: File[]) => {
    setUploading(true);
    setProgress(0);

        });

    } catch (error) {
      message.error('上传失败');
    } finally {
      setUploading(false);
      setProgress(0);
    }
  };

  return (
    <Upload
      draggable
      multiple
      accept=".pdf,.doc,.docx,.xlsx,.ppt,.pptx,.txt,.md"
      showUploadList={false}
      customRequest={({ fileList }) => handleUpload(fileList)}
    >
      <Button icon={<IconUpload />} loading={uploading} theme="solid">
        {uploading ? `上传中... ${progress}%` : '点击或拖拽上传文档'}
      </Button>
      {uploading && <Progress percent={progress} showInfo={false} />}
```

```go
// DocumentParser 文档解析器接口
type DocumentParser interface {
    Parse(ctx context.Context, filePath string, config map[string]interface{}) (*ParseResult, error)

// ParserRegistry 解析器注册表
type ParserRegistry struct {
    parsers map[string]DocumentParser // key: file extension
}

// RegisterParser 注册解析器
func (r *ParserRegistry) RegisterParser(parser DocumentParser) {
    for _, ext := range parser.SupportedExtensions() {
        r.parsers[ext] = parser
    }
}

// Parse 解析文档
func (r *ParserRegistry) Parse(ctx context.Context, filePath string, fileType string, config map[string]interface{}) (*ParseResult, error) {
    parser, exists := r.parsers[fileType]

        return nil, fmt.Errorf("no parser found for file type: %s", fileType)

    return parser.Parse(ctx, filePath, config)
}
```

### 8.2 可配置分块器框架

```go
package chunker

// Chunker 分块器接口
type Chunker interface {
    Chunk(ctx context.Context, content string, config map[string]interface{}) ([]*Chunk, error)
}

// ChunkerRegistry 分块器注册表
type ChunkerRegistry struct {
    chunkers map[string]Chunker // key: strategy type
}

// FixedLengthChunker 固定长度分块器
type FixedLengthChunker struct{}

func (c *FixedLengthChunker) Chunk(ctx context.Context, content string, config map[string]interface{}) ([]*Chunk, error) {
    chunkSize := config["chunkSize"].(int)
    overlap := config["chunkOverlap"].(int)

    chunks := make([]*Chunk, 0)
    start := 0

    for start < len(content) {
        end := start + chunkSize
        if end > len(content) {
            end = len(content)
        }

        chunks = append(chunks, &Chunk{
            Content:   content[start:end],
            StartPos:  start,
            EndPos:    end,
            ChunkIndex: len(chunks),
        })

        start = end - overlap
    }

    return chunks, nil
}
```
