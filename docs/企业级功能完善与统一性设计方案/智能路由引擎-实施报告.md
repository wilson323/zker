### 请求流程

1. **前端发起请求**
```typescript
const response = await routingService.recognizeIntent(tenantId, text);
```

2. **HTTP层**
```
POST /api/routing/intents/recognize
Content-Type: application/json

{
  "tenant_id": "xxx",
  "text": "用户输入",
  "strategy": "hybrid"
}
```

3. **Handler层处理**
```go
func (h *IntentRecognitionHandler) RecognizeIntent(ctx context.Context, c *app.RequestContext) {
    // 1. 参数绑定和验证
    var req RecognizeIntentRequest
    if err := c.BindAndValidate(&req); err != nil {
        httputil.BadRequest(c, err.Error())
        return
    }

    // 2. 调用Service层
    result, err := h.intentService.RecognizeIntent(ctx, req.TenantID, req.Text, req.Strategy)

    // 3. 返回响应
    c.JSON(http.StatusOK, RecognizeIntentResponse{...})
}
```

4. **Service层处理**
```go
func (s *IntentRecognitionService) RecognizeIntent(...) (*entity.IntentRecognitionResult, error) {
    // 业务逻辑处理
    intents := s.intentRepo.GetActiveIntentsByTenant(ctx, tenantID)

    // 意图匹配
    matches := s.hybridMatcher.Match(ctx, &MatchInput{...})

    // 返回结果
    return &entity.IntentRecognitionResult{...}, nil
}
```
