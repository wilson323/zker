## 💎 核心设计理念

### 1. 配置优先（Configuration-First）

**核心理念**: 70-90% 的功能通过数据库配置实现，仅 10-30% 需要编码

**优势**:
- ✅ 大幅降低开发成本（70%降低）
- ✅ 快速响应用户需求
- ✅ 无需发版即可调整功能
- ✅ 降低维护成本

**实现**:
- 通用 CRUD 框架
- 动态表单引擎
- 规则引擎
- 权限配置系统

### 2. 复用优先（Reuse-First）

**核心理念**: 100% 复用 zker 现有成熟系统

**可复用系统**:
- ✅ BotBuilder（低代码Bot构建器）
- ✅ WorkflowEditor（工作流编辑器）
- ✅ Plugin Store（插件商店）
- ✅ User System（用户权限系统）

**优势**:
- ✅ 节省 7.5 个月开发时间
- ✅ 节省 ¥280万 开发成本
- ✅ 成熟稳定，已有大量用户验证
- ✅ 降低技术风险

### 3. 企业级设计（Enterprise-Grade）

**多租户隔离**:
- ✅ 应用层: tenant_id 上下文传递
- ✅ 数据层: Row-Level Security
- ✅ 缓存层: 租户隔离 Key
- ✅ 搜索层: 租户索引隔离

**权限控制**:
- ✅ RBAC（基于角色的访问控制）
- ✅ 数据权限（部门级、用户级）
- ✅ 操作权限（按钮级、接口级）

**审计合规**:
- ✅ 完整操作审计日志
- ✅ 数据脱敏（手机号、身份证等）
- ✅ 等保三级合规
- ✅ GDPR 合规

## 🛠️ 技术架构

### 技术栈

#### 后端技术栈
```yaml
语言: Go 1.23
框架: Hertz (字节跳动开源)
ORM: GORM
数据库:
  - MySQL 8.4.5      # 主数据库
  - Redis 8.0        # 缓存 + 会话
  - Elasticsearch 8.18.0  # 全文搜索
  - Milvus 2.5.10    # 向量数据库（记忆）
  - InfluxDB         # 监控时序数据
  - Neo4j/NebulaGraph # 知识图谱
消息队列: NSQ
配置中心: etcd 3.5
```

#### 前端技术栈
```yaml
语言: TypeScript 5.6
框架: React 18.3
UI库: Semi Design
状态管理: Zustand
编辑器: Monaco Editor
图表: ECharts
构建工具: Rsbuild (Rspack)
包管理: Rush.js (monorepo)
```

#### 基础设施
```yaml
容器化: Docker + Kubernetes
服务网格: Istio (可选)
监控告警: Prometheus + Grafana
日志收集: ELK Stack
对象存储: MinIO
负载均衡: Nginx + Keepalived
```

### 架构模式

1. **DDD (领域驱动设计)**
   - 领域层 (domain/): 业务实体和领域逻辑
   - 应用层 (application/): 应用服务和用例
   - 接口层 (api/): HTTP 接口和路由
   - 基础设施层 (infra/): 技术实现

2. **微服务架构**
   - 用户服务 (user-service)
   - Bot 服务 (bot-service)
   - 对话服务 (conversation-service)
   - 知识服务 (knowledge-service)
   - 技能服务 (skill-service)
   - 租户服务 (tenant-service)
   - 计费服务 (billing-service)

3. **多租户架构**
   - 共享数据库、共享 Schema (最经济)
   - Row-Level Security 隔离
   - 租户上下文自动传递
   - 缓存、搜索、存储均隔离
