# 智能路由引擎 - 快速启动指南

## 🚀 快速开始

### 后端服务启动

#### 1. 注册路由

在 `backend/main.go` 或应用初始化文件中添加：

```go
package main

import (
    "github.com/cloudwego/hertz/pkg/app/server"
    "github.com/coze-dev/coze-studio/backend/api/router/coze"
    "github.com/coze-dev/coze-studio/backend/api/handler/coze/routing"
    "github.com/coze-dev/coze-studio/backend/application/routing"
    "go.uber.org/zap"
)

func main() {
    r := server.Default()

    // 初始化Service层（需要先实现）
    logger := zap.NewExample()

    intentService := routing.NewIntentRecognitionService(...)
    optimizerService := routing.NewRoutingOptimizerService(...)
    ruleConfigService := routing.NewRoutingRuleConfigService(...)
    abTestService := routing.NewABTestService(...)
    learningService := routing.NewRoutingLearningService(...)

    // 创建Handler容器
    handlers := routing.NewRoutingHandlers(
        intentService,
        optimizerService,
        ruleConfigService,
        abTestService,
        learningService,
        logger,
    )

    // 注册路由
    coze.RegisterRoutingRoutes(r, handlers)

    r.Run(":8080")
}
```

## 💡 常见问题

### Q1: 如何初始化Service层？

A: Service层需要依赖Repository层，参考现有的Service实现：

```go
package routing

import (
    "github.com/coze-dev/coze-studio/backend/domain/routing/repository"
    "github.com/coze-dev/coze-studio/backend/domain/routing/service"
)

type IntentRecognitionService struct {
    intentRepo  repository.IntentRepository
    sampleRepo  repository.IntentSampleRepository
    llmClient   LLMClient
    vectorStore VectorStore
    logger      *zap.Logger
}

func NewIntentRecognitionService(
    intentRepo repository.IntentRepository,
    sampleRepo repository.IntentSampleRepository,
    llmClient LLMClient,
    vectorStore VectorStore,
    logger *zap.Logger,
) *IntentRecognitionService {
    return &IntentRecognitionService{
        intentRepo:  intentRepo,
        sampleRepo:  sampleRepo,
        llmClient:   llmClient,
        vectorStore: vectorStore,
        logger:      logger,
    }
}
```

### Q2: 前端如何调用API？

A: 使用现有的API客户端：

```typescript
import { getRoutingService } from '@coze-studio/api-client';

const routingService = await getRoutingService();

// 识别意图
const result = await routingService.recognizeIntent({
  tenant_id: tenantId,
  text: userInput,
  strategy: 'hybrid',
});

// 获取意图列表
const intents = await routingService.getIntents(tenantId, {
  is_active: true,
  page: 1,
  page_size: 20,
});
```

### Q3: 如何调试Handler？

A: 使用Hertz的测试工具：

```go
import (

func TestHandler(t *testing.T) {
    handler := &IntentRecognitionHandler{...}

    ctx := context.Background()
    c := &app.RequestContext{}
    c.Request.SetBody([]byte(`{"tenant_id": "test", "text": "hello"}`))

    handler.RecognizeIntent(ctx, c)

}
```
