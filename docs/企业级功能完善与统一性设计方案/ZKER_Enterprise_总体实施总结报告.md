## 🛠️ 技术架构总结

### 核心技术栈

#### 后端技术栈
```go
├── 框架: Hertz (字节跳动)
├── ORM: GORM
├── 数据库:
│   ├── MySQL 8.4.5 (主数据库)
│   ├── Redis 8.0 (缓存 + 会话)
│   ├── Elasticsearch 8.18.0 (全文搜索)
│   ├── Milvus 2.5.10 (向量数据库)
│   ├── InfluxDB (监控时序数据)
│   └── Neo4j/NebulaGraph (知识图谱)
├── 消息队列: NSQ
└── 配置中心: etcd 3.5
```

#### 前端技术栈
```typescript
├── 框架: React 18.3
├── 语言: TypeScript 5.6
├── UI库: Semi Design
├── 状态管理: Zustand
├── 编辑器: Monaco Editor
├── 图表: ECharts
├── 构建工具: Rsbuild (Rspack)
└── 包管理: Rush.js (monorepo)
```

#### 基础设施
```yaml
容器化: Docker + Kubernetes
服务网格: Istio (可选)
监控告警: Prometheus + Grafana
日志收集: ELK Stack
对象存储: MinIO
负载均衡: Nginx + Keepalived
```

### 关键架构模式

1. **DDD (领域驱动设计)**
   - 领域层: domain/
   - 应用层: application/
   - 接口层: api/
   - 基础设施层: infra/

2. **微服务架构**
   - 用户服务
   - Bot服务
   - 对话服务
   - 知识服务
   - 技能服务
   - 租户服务
   - 计费服务

3. **多租户隔离**
   - 应用层: tenant_id 上下文传递
   - 数据层: Row-Level Security
   - 缓存层: 租户隔离Key
   - 搜索层: 租户索引隔离
