### 问题2: 表结构差异

**Coze Studio规范**:
- 表名: `users`（小写复数）
- 主键: `id` (BIGINT)
- 软删除: `deleted_at` (BIGINT)
- 时间戳: `created_at`, `updated_at` (BIGINT, 毫秒)

**ioedream实际结构**:
- 表名: `t_common_user`（带前缀）
- 主键: `user_id` (BIGINT)
- 软删除: `deleted_flag` (TINYINT)
- 时间戳: `create_time`, `update_time` (DATETIME)

```sql
-- 创建tenants表
CREATE TABLE `tenants` (
    `tenant_id` VARCHAR(36) PRIMARY KEY,
    `tenant_name` VARCHAR(200) NOT NULL,
    `tenant_type` ENUM('individual', 'team', 'enterprise') NOT NULL,
    `status` ENUM('active', 'suspended', 'deleted') DEFAULT 'active',
    `subscription_tier` ENUM('free', 'pro', 'enterprise') DEFAULT 'free',
    `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP,
    `update_time` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    INDEX `idx_status_type` (`status`, `tenant_type`)
) CHARSET=utf8mb4;

-- 为t_common_user添加tenant_id列
ALTER TABLE `t_common_user`
ADD COLUMN `tenant_id` VARCHAR(36) NULL COMMENT '租户ID' AFTER `user_id`,
ADD INDEX `idx_tenant_id` (`tenant_id`);

-- 创建user_tenants关联表
CREATE TABLE `user_tenants` (
    `user_tenant_id` VARCHAR(36) PRIMARY KEY,
    `user_id` BIGINT NOT NULL,
    `tenant_id` VARCHAR(36) NOT NULL,
    `role` ENUM('owner', 'admin', 'member') DEFAULT 'member',
    `is_default` BOOLEAN DEFAULT FALSE,
    `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP,
    `update_time` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (`user_id`) REFERENCES `t_common_user`(`user_id`),
    FOREIGN KEY (`tenant_id`) REFERENCES `tenants`(`tenant_id`),
    UNIQUE INDEX `uk_user_tenant` (`user_id`, `tenant_id`)
) CHARSET=utf8mb4;
```

#### 步骤3: 为现有用户创建租户

```sql
-- 为每个用户创建个人租户
INSERT INTO `tenants` (
    `tenant_id`,
    `tenant_name`,
    `tenant_type`,
    `status`,
    `subscription_tier`
)
SELECT
    CONCAT('individual-user-', CAST(`user_id` AS CHAR)),
    CONCAT(`username`, '\'s Space'),
    'individual',
    'active',
    'free'
FROM `t_common_user`
WHERE `deleted_flag` = 0;

-- 更新用户的tenant_id
UPDATE `t_common_user` u
SET u.`tenant_id` = CONCAT('individual-user-', CAST(u.`user_id` AS CHAR))
WHERE u.`deleted_flag` = 0
  AND u.`tenant_id` IS NULL;

-- 创建user_tenants关联
INSERT INTO `user_tenants` (
    `user_tenant_id`,
    `user_id`,
    `tenant_id`,
    `role`,
    `is_default`
)
SELECT
    UUID(),
    u.`user_id`,
    u.`tenant_id`,
    'owner',
    TRUE
FROM `t_common_user` u
WHERE u.`deleted_flag` = 0
  AND u.`tenant_id` IS NOT NULL;
```
