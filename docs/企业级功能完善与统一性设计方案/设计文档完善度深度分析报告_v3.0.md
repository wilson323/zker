   ```
   ALGORITHM: IntentRecognition

   INPUT: user_input (string), context (ConversationContext)
   OUTPUT: intent (Intent), confidence (float)

   1. 预处理
      a. 文本清洗: 去除特殊字符、HTML标签
      b. 分词: 使用jieba分词
      c. 停用词过滤: 去除无意义词

   2. 特征提取
      a. 提取关键词 (TF-IDF)
      b. 提取实体 (NER: 人名、地名、机构名)
      c. 提取短语 (n-gram)

   3. 意图分类
      a. 规则匹配
         IF 包含"价格"、"多少钱" THEN intent = knowledge_query
         ELSE IF 包含"创建"、"新建" THEN intent = task_execution
         ELSE IF 包含"销售"、"营业额" THEN intent = data_analysis
         ...

      b. 向量检索
         - 将user_input转换为向量
         - 在Milvus中检索Top K相似意图
         - 获取最相似意图及其相似度分数

      c. LLM分类
         - 调用通义千问/GPT-4进行意图分类
         - 输入: user_input + context
         - 输出: intent + confidence

      d. 融合决策
         - IF 规则匹配成功 THEN 使用规则意图
         - ELSE IF LLM置信度 > 0.8 THEN 使用LLM意图
         - ELSE 使用向量检索意图

   4. 置信度计算
      confidence = 规则匹配分数 * 0.3 + 向量相似度 * 0.3 + LLM置信度 * 0.4

   5. 返回结果
      RETURN (intent, confidence)
   ```

**工作量**: 10人天
**优先级**: P0
