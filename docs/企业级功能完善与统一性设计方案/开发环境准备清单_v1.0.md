## 🔧 通用工具安装

### 1. Git

**版本要求**: ≥ 2.30.0

**安装验证**:
```bash
git --version
# 输出: git version 2.xx.x
```

**配置**:
```bash
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
git config --global core.autocrlf input  # macOS/Linux
git config --global core.autocrlf true   # Windows
```

---

### 2. Docker

**版本要求**: ≥ 20.10.0

**安装验证**:
```bash
docker --version
docker-compose --version
```

**配置（macOS/Windows）**:
- 分配至少4GB内存
- 分配至少2个CPU核心
- 共享磁盘驱动器

**配置（Linux）**:
```bash
# 将用户添加到docker组
sudo usermod -aG docker $USER

# 重新登录后验证
docker ps
```

---

### 3. VS Code

**安装**: https://code.visualstudio.com/

**必装插件（通用）**:
- GitLens - Git超级增强
- GitHub Copilot - AI代码助手
- Markdown All in One - Markdown支持

## 🎨 前端开发环境（研发C）

### 1. Node.js

**版本要求**: ≥ 18.0.0（推荐LTS版本）

**安装**:
```bash
# 使用nvm安装（推荐）
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install 18
nvm use 18
```

**验证**:
```bash
node --version
npm --version
```

---

### 2. Rush.js

**安装**:
```bash
npm install -g @microsoft/rush
```

**验证**:
```bash
rush --version
```

---

### 3. 前端VS Code插件

**必装插件**:
- ES Lint - JavaScript/TypeScript代码检查
- Prettier - Code formatter
- TypeScript Vue Plugin (Volar) - Vue 3支持
- Auto Import - 自动导入
- Import Cost - 显示导入包的大小
- Tailwind CSS IntelliSense - Tailwind支持

---

### 4. 前端环境初始化

```bash
# 1. 克隆项目
git clone https://github.com/your-org/coze-studio.git
cd coze-studio

# 2. 安装依赖
cd frontend
rush update

# 3. 构建项目
rush build

# 4. 启动开发服务器
cd apps/coze-studio
npm run dev
```

**验证**: 访问 http://localhost:8888

## 🔧 后端开发环境（研发A、研发B）

### 1. Go

**版本要求**: 1.24.0

**安装**:
```bash
# macOS
brew install go

# Linux
wget https://go.dev/dl/go1.24.0.linux-amd64.tar.gz
sudo tar -C /usr/local -xzf go1.24.0.linux-amd64.tar.gz

# Windows
# 下载安装包: https://go.dev/dl/
```

**配置环境变量**:
```bash
# ~/.bashrc 或 ~/.zshrc
export GOPATH=$HOME/go
export GOROOT=/usr/local/go
export PATH=$PATH:$GOPATH/bin:$GOROOT/bin
```

**验证**:
```bash
go version
# 输出: go version go1.24.0 xxx
```

---

### 2. Go工具链

**安装工具**:
```bash
# 安装Go工具
go install golang.org/x/tools/cmd/...@latest

# 安装golangci-lint
curl -sSfL https://raw.githubusercontent.com/golangci/golangci-lint/master/install.sh | sh -s -- -b $(go env GOPATH)/bin

# 安装go-swagger
go install github.com/go-swagger/go-swagger/cmd/swagger@latest

# 安装Atlas（数据库迁移）
curl -sSf https://atlasgo.sh | sh
```

**验证**:
```bash
golangci-lint version
swagger version
atlas version
```

---

### 3. 后端VS Code插件

**必装插件**:
- Go - Go语言支持
- Error Lens - 内联显示错误
- Makefile Support - Makefile语法高亮

---

### 4. 后端环境初始化

```bash
# 1. 克隆项目（如果还没克隆）
cd coze-studio

# 2. 启动中间件服务
cd docker
docker-compose up -d

# 3. 等待服务就绪
sleep 30

# 4. 初始化数据库
make sql_init

# 5. 配置环境变量
cd ../backend
cp conf/.env.example conf/.env
# 编辑conf/.env，配置数据库连接等

# 6. 同步数据库schema
make sync_db

# 7. 启动Go服务器
make server
```

**验证**:
```bash
curl http://localhost:8080/health
# 输出: {"status":"ok"}
```

## 🔧 常见问题

### 问题1: Docker服务无法启动

**症状**: `Cannot connect to the Docker daemon`

**解决方案**:
```bash
# macOS/Windows: 从应用程序菜单启动Docker Desktop

# Linux:
sudo systemctl start docker
sudo systemctl enable docker
```

---

### 问题2: 端口冲突

**症状**: `port is already allocated`

**解决方案**:
```bash
# 查看端口占用
lsof -i :8080  # macOS/Linux
netstat -ano | findstr :8080  # Windows

# 修改端口配置
# 编辑 docker/docker-compose.yml
# 修改端口映射，如 "8080:8080" -> "8081:8080"
```

---

### 问题3: 数据库连接失败

**症状**: `connection refused` 或 `unknown database`

**解决方案**:
```bash
# 1. 检查MySQL容器状态
docker ps | grep mysql

# 2. 查看MySQL日志
docker logs coze-mysql-1

# 3. 进入MySQL容器
docker exec -it coze-mysql-1 mysql -uroot -p

# 4. 创建数据库
CREATE DATABASE IF NOT EXISTS coze;
```

---

### 问题4: Node.js版本不兼容

**症状**: `node version does not match`

**解决方案**:
```bash
# 使用nvm切换版本
nvm install 18
nvm use 18

# 设置默认版本
nvm alias default 18
```

---

### 问题5: Go模块下载缓慢

**症状**: `go get` 速度很慢

**解决方案**:
```bash
# 使用Go国内代理
go env -w GOPROXY=https://goproxy.cn,direct
go env -w GO111MODULE=on
```
