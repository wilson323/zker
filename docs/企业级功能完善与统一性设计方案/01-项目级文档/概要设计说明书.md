## 1. 引言

### 1.1 编写目的

本文档是 zker Enterprise Edition 系统的概要设计说明书 (HLD),旨在:

1. **定义系统架构**: 描述系统的总体架构、技术选型、模块划分
2. **指导详细设计**: 为详细设计和编码提供高层指导
3. **技术决策记录**: 记录关键技术选型和设计决策
4. **团队协作**: 在架构师、开发、测试之间建立技术共识

### 1.2 项目概述

**zker Enterprise Edition** 是基于开源 zker 打造的企业级 Multi-Tenant SaaS 平台,核心特性:

✅ **Multi-Tenant SaaS**: 支持N个企业(租户)独立使用
✅ **完全隔离**: 租户间数据、计算、缓存、存储100%隔离
✅ **功能完整**: 对齐鲸智百应100%功能
✅ **开源可定制**: 基于开源,可深度定制
✅ **成本可控**: 私有化部署,无订阅费用

### 1.3 设计原则

#### 1.3.1 SOLID原则

- **单一职责原则 (SRP)**: 每个模块只负责一个功能领域
- **开闭原则 (OCP)**: 对扩展开放,对修改关闭
- **里氏替换原则 (LSP)**: 子类可以替换父类
- **接口隔离原则 (ISP)**: 接口专一,避免"胖接口"
- **依赖倒置原则 (DIP)**: 依赖抽象而非具体实现

#### 1.3.2 KISS原则

- Keep It Simple, Stupid
- 追求架构和代码的简洁
- 避免过度设计

#### 1.3.3 DRY原则

- Don't Repeat Yourself
- 自动识别重复代码模式
- 主动抽象和复用

#### 1.3.4 YAGNI原则

- You Aren't Gonna Need It
- 只实现当前明确所需的功能
- 抵制过度设计

## 2. 系统总体架构

### 2.1 架构风格

**架构模式**: 分层架构 + 微服务架构 + 领域驱动设计 (DDD)

**理由**:
- **分层架构**: 清晰的职责分离,易于维护
- **微服务架构**: 独立部署、独立扩展
- **DDD**: 业务逻辑与技术实现分离,提高业务灵活性

**Repository实现**:
```go
// GORM实现
type gormUserRepository struct {
    db *gorm.DB
}

func NewUserRepository(db *gorm.DB) UserRepository {
    return &gormUserRepository{db: db}
}

func (r *gormUserRepository) GetByID(ctx context.Context, id string) (*User, error) {
    var user User
    err := r.db.WithContext(ctx).Where("id = ?", id).First(&user).Error
    if err != nil {
        return nil, err
    }
    return &user, nil
}

// Redis实现 (缓存)
type cachedUserRepository struct {
    base  UserRepository
    cache *redis.Client
}

func NewCachedUserRepository(base UserRepository, cache *redis.Client) UserRepository {
    return &cachedUserRepository{
        base:  base,
        cache: cache,
    }
}

func (r *cachedUserRepository) GetByID(ctx context.Context, id string) (*User, error) {
    // 1. 尝试从缓存获取
    key := fmt.Sprintf("user:%s", id)
    cached, _ := r.cache.Get(ctx, key).Result()
    if cached != "" {
        var user User
        json.Unmarshal([]byte(cached), &user)
        return &user, nil
    }

    // 2. 从数据库获取
    user, err := r.base.GetByID(ctx, id)
    if err != nil {
        return nil, err
    }

    // 3. 写入缓存
    data, _ := json.Marshal(user)
    r.cache.Set(ctx, key, data, 10*time.Minute)

    return user, nil
}
```

## 4. 模块设计

### 4.1 模块划分原则

1. **按业务领域划分**: 遵循DDD,每个模块对应一个业务领域
2. **高内聚低耦合**: 模块内部高度内聚,模块之间低耦合
3. **独立部署**: 每个模块可独立部署、独立扩展
4. **API优先**: 模块间通过API通信

## 6. 数据架构设计

### 6.1 数据存储策略

#### 6.1.1 数据分类

| 数据类型 | 存储选型 | 理由 |
|---------|---------|------|
| **主数据** | MySQL | 事务支持,数据一致性 |
| **会话数据** | Redis | 高性能,支持过期 |
| **日志数据** | Elasticsearch | 全文检索,分析能力 |
| **向量数据** | Milvus | 向量检索,高性能 |
| **分析数据** | ClickHouse | 列式存储,分析性能 |
| **文件数据** | MinIO | 对象存储,大文件支持 |

#### 6.1.2 数据隔离策略

**Row-Level隔离** (小租户, <1000用户):
```sql
-- 所有表包含 tenant_id 字段
CREATE TABLE users (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    tenant_id VARCHAR(64) NOT NULL,
    -- ...
    INDEX idx_tenant_id (tenant_id)
);

-- 查询时自动过滤
SELECT * FROM users WHERE tenant_id = ? AND ...;
```

**Schema隔离** (中租户, 1000-10000用户):
```sql
-- 每个租户一个Schema
CREATE SCHEMA tenant_a;
CREATE TABLE tenant_a.users (...);

CREATE SCHEMA tenant_b;
CREATE TABLE tenant_b.users (...);
```

**Database隔离** (大租户, >10000用户):
```sql
-- 每个租户一个Database
CREATE DATABASE tenant_a;
CREATE TABLE tenant_a.users (...);

CREATE DATABASE tenant_b;
CREATE TABLE tenant_b.users (...);
```

#### 6.2.2 分库分表策略

```go
// 按租户ID分片
func getShardID(tenantID string) int {
    hash := crc32.ChecksumIEEE([]byte(tenantID))
    return int(hash % 10) // 10个分片
}

// 获取分片数据库
func getDB(tenantID string) *gorm.DB {
    shardID := getShardID(tenantID)
    return dbs[shardID]
}
```

```
Shard 0: tenants, users (租户和用户)

Shard 2: conversations, messages (对话相关)
Shard 3: knowledge_bases, documents (知识库相关)
...
```

#### 6.3.3 缓存更新策略

**Cache Aside**:
```go
// 读取
func (r *cachedBotRepository) GetByID(ctx context.Context, id string) (*Bot, error) {
    // 1. 从缓存读取
    key := fmt.Sprintf("bot:%s", id)
    cached, _ := r.cache.Get(ctx, key).Result()
    if cached != "" {
        var bot Bot
        json.Unmarshal([]byte(cached), &bot)
        return &bot, nil
    }

    // 2. 从数据库读取
    bot, err := r.base.GetByID(ctx, id)
    if err != nil {
        return nil, err
    }

    // 3. 写入缓存
    data, _ := json.Marshal(bot)
    r.cache.Set(ctx, key, data, 10*time.Minute)

    return bot, nil
}

// 更新
func (r *cachedBotRepository) Update(ctx context.Context, bot *Bot) error {
    // 1. 更新数据库
    err := r.base.Update(ctx, bot)
    if err != nil {
        return err
    }

    // 2. 删除缓存
    key := fmt.Sprintf("bot:%s", bot.ID)
    r.cache.Del(ctx, key)

    return nil
}
```

```go
func (m *AuthorizationMiddleware) RequirePermission(resource string, action string) app.HandlerFunc {
    return func(ctx context.Context, c *app.RequestContext) {
        userID := ctx.Value("user_id").(string)
        tenantID := ctx.Value("tenant_id").(string)

        // 使用Casbin检查权限
        allowed, _ := m.enforcer.Enforce(
            fmt.Sprintf("%s:%s", tenantID, userID),
            resource,
            action,
        )

        if !allowed {
            c.JSON(403, map[string]string{
                "error": "权限不足",
                "required": fmt.Sprintf("%s:%s", resource, action),
            })
            c.Abort()
            return
        }

        c.Next(ctx)
    }
}
```
