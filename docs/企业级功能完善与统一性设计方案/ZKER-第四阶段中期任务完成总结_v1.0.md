### 🚀 核心功能特性

#### 1. NSQ生产者

**功能**：
- ✅ 连接池管理（自动扩缩容）
- ✅ 自动重连（断线自动重连）
- ✅ 普通发布、延迟发布、批量发布
- ✅ 自定义重试策略（指数退避、固定延迟）
- ✅ 完整指标收集（Prometheus）

**使用示例**：
```go
// 简单发布
err := producer.Publish(ctx, "knowledge_document", task)

// 延迟发布（5分钟后执行）
err := producer.PublishDelayed(ctx, "workflow", 5*time.Minute, task)

// 批量发布
err := producer.PublishBatch(ctx, "knowledge_document", tasks)
```

#### 2. NSQ消费者

**功能**：
- ✅ 并发消费（MaxInFlight配置）
- ✅ 指数退避重试（1s, 2s, 4s, 8s...）
- ✅ 重试追踪和监控
- ✅ 自动转入死信队列（3次重试失败后）
- ✅ 优雅关闭（等待30秒完成处理）

**使用示例**：
```go
// 注册任务处理器
handler := queue.TaskHandlerFunc(func(ctx context.Context, taskType string, taskData []byte) error {
    // 处理任务
    return nil
})

manager.RegisterTaskWithConsumer("my_task", handler)
manager.Start()
```

#### 3. 死信队列（DLQ）

**功能**：
- ✅ 保存完整失败上下文（错误信息、堆栈、时间戳）
- ✅ 单条/批量重放
- ✅ 可插拔存储（内存/Redis/MySQL）
- ✅ 过期清理（默认72小时）

**使用示例**：
```go
// 重放失败任务
err := dlq.ReplayDLQ(ctx, "knowledge_document")
```

#### 4. 队列管理器

**功能**：
- ✅ 统一任务入队/出队接口
- ✅ 任务类型注册和管理
- ✅ 动态消费者管理
- ✅ 完整监控指标

#### 5. 业务任务封装
