### 🏗️ 缓存架构

**权限缓存**（多级缓存）：
```
L1: 本地LRU（1分钟）
  ↓ Miss
L2: Redis（5分钟）
  ↓ Miss
L3: 数据库
```

**配额缓存**（原子操作）：
```
1. 数据库扣减配额
2. 删除Redis缓存
3. 下次查询时重新加载
```

**配置缓存**（4级架构）：
```
L1: 全量配置（定时1分钟）
  ↓ Miss
L2: 本地LRU
  ↓ Miss
L3: Redis
  ↓ Miss
L4: 数据库
```
