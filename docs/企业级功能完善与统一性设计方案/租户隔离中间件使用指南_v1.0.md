## 🎯 概述

### 核心功能

租户隔离中间件（`TenantIsolationMiddleware`）是**企业级多租户SaaS架构的核心安全组件**，负责：

1. **提取租户ID**：从HTTP Header、Session、JWT Token中提取`tenant_id`
2. **验证租户状态**：检查租户是否存在、是否激活、是否被删除
3. **注入Context**：将`tenant_id`注入到请求context中，供后续业务逻辑使用
4. **追踪和日志**：记录租户信息到分布式追踪和日志系统

### 安全保障

✅ **防止数据泄露**：确保用户只能访问自己租户的数据
✅ **防止跨租户攻击**：阻止恶意用户通过修改请求访问其他租户数据
✅ **审计追踪**：所有操作都关联租户ID，便于审计和故障排查

## 🚀 快速开始

### 1. 在路由中启用中间件

```go
package main

import (
    "github.com/cloudwego/hertz/pkg/app/server"
    "github.com/coze-studio/coze-studio/backend/api/middleware"
)

func main() {
    h := server.Default()

    // 全局启用租户隔离中间件
    h.Use(middleware.TenantIsolationMiddleware())

    // 业务路由
    h.GET("/api/bots", listBots)
    h.POST("/api/bots", createBot)

    h.Run(":8888")
}
```

### 2. 在业务代码中使用tenant_id

```go
package handlers

import (
    "context"
    "github.com/cloudwego/hertz/pkg/app"
    "github.com/coze-studio/coze-studio/backend/api/middleware"
    "github.com/coze-studio/coze-studio/backend/pkg/ctxcache"
    "github.com/coze-studio/coze-studio/backend/types/consts"
)

// ListBots 列出当前租户的Bot
func ListBots(ctx context.Context, c *app.RequestContext) {
    // 方式1：使用辅助函数（推荐）
    tenantID := middleware.GetTenantIDFromContext(ctx)

    // 方式2：直接从context获取
    // tenantID := ctx.Value(middleware.TenantIDKey)

    // 方式3：从ctxcache获取
    // tenantID, ok := ctxcache.Get[string](ctx, consts.TenantIDKeyInCtx)

    // 数据库查询（自动添加租户隔离）
    bots, err := botService.ListByTenant(ctx, tenantID)
    if err != nil {
        c.JSON(500, map[string]interface{}{
            "error": err.Error(),
        })
        return
    }

    c.JSON(200, map[string]interface{}{
        "data": bots,
        "tenant_id": tenantID,
    })
}

// CreateBot 创建Bot（强制要求租户ID）
func CreateBot(ctx context.Context, c *app.RequestContext) {
    // 使用MustGetTenantIDFromContext强制要求有效的租户ID
    tenantID := middleware.MustGetTenantIDFromContext(ctx)

    var req CreateBotRequest
    if err := c.BindAndValidate(&req); err != nil {
        c.JSON(400, map[string]interface{}{"error": err.Error()})
        return
    }

    // 创建Bot（自动关联租户）
    bot, err := botService.Create(ctx, tenantID, &req)
    if err != nil {
        c.JSON(500, map[string]interface{}{"error": err.Error()})
        return
    }

    c.JSON(201, map[string]interface{}{
        "data": bot,
        "tenant_id": tenantID,
    })
}
```

### 3. 客户端调用API

```bash
# 方式1：通过HTTP Header传递tenant_id（推荐）
curl -X GET http://localhost:8888/api/bots \
  -H "X-Tenant-ID: your-tenant-123" \
  -H "Authorization: Bearer your-jwt-token"

# 方式2：通过Cookie传递（Session包含tenant_id）
curl -X GET http://localhost:8888/api/bots \
  -H "Cookie: session_key=your-session-key"

# 方式3：JWT Token包含tenant_id（TODO：数据迁移后支持）

```

## 📚 API参考

### 中间件函数

#### TenantIsolationMiddleware()

**签名**: `func TenantIsolationMiddleware() app.HandlerFunc`

**说明**: 租户隔离中间件，提取并验证tenant_id，注入到context

**提取优先级**:
1. HTTP Header: `X-Tenant-ID` （最高优先级）
2. Session: `session.TenantID` （TODO：数据迁移后启用）
3. JWT Token: `claims.tenant_id` （TODO：JWT改造后启用）
4. 默认值: `default` （兼容模式，数据迁移后移除）

**示例**:
```go
h.Use(middleware.TenantIsolationMiddleware())
```

---

#### RequireTenantID()

**签名**: `func RequireTenantID() app.HandlerFunc`

**说明**: 强制要求有效的tenant_id，拒绝默认租户ID

**使用场景**:
- 租户管理API
- 数据隔离要求严格的接口

**示例**:
```go
// 租户管理接口必须提供有效的tenant_id
tenantGroup := h.Group("/api/tenants")
tenantGroup.Use(middleware.RequireTenantID())
{
    tenantGroup.GET("/:tenant_id", getTenant)
    tenantGroup.PUT("/:tenant_id", updateTenant)
}
```

---

### 辅助函数

#### GetTenantIDFromContext()

**签名**: `func GetTenantIDFromContext(c context.Context) string`

**说明**: 从context中获取tenant_id，如果没有则返回默认租户ID

**返回值**:
- 成功: 返回tenant_id字符串
- 失败: 返回`DefaultTenantID`（"default"）

**示例**:
```go
tenantID := middleware.GetTenantIDFromContext(ctx)
```

---

#### MustGetTenantIDFromContext()

**签名**: `func MustGetTenantIDFromContext(c context.Context) string`

**说明**: 从context中获取tenant_id，如果没有有效tenant_id则panic

**返回值**:
- 成功: 返回tenant_id字符串
- 失败: panic（整个请求终止）

**使用场景**: 租户强相关的业务逻辑

**示例**:
```go
// 租户管理接口必须明确租户
tenantID := middleware.MustGetTenantIDFromContext(ctx)
```

---

#### TenantIDToInt64()

**签名**: `func TenantIDToInt64(tenantID string) (int64, error)`

**说明**: 将tenant_id字符串转换为int64（临时兼容函数）

**注意**: 这是一个**临时兼容函数**，用于支持当前系统使用int64类型的user_id
数据迁移后，tenant_id统一为string类型（UUID），此函数将被移除

**返回值**:
- 成功: (int64, nil)
- 失败: (0, error) - 当tenant_id是UUID格式或无法转换时

**示例**:
```go
tenantID := "123456"
id, err := middleware.TenantIDToInt64(tenantID)
if err != nil {
    // 处理错误
}
fmt.Printf("Tenant ID as int64: %d\n", id)
```

### 工作流程

```
┌─────────────┐
│ HTTP Request │
└──────┬──────┘
       │
       ▼
┌─────────────────────────────────┐
│ TenantIsolationMiddleware       │

│    - /api/passport/*            │
│    - /api/health/*              │
│    - /api/metrics/*             │
└────────┬────────────────────────┘
         │ 否
         ▼
┌─────────────────────────────────┐
│ 2. 提取tenant_id                │
│    优先级: Header > Session      │
│            > JWT > Default       │
└────────┬────────────────────────┘
         │
         ▼
┌─────────────────────────────────┐
│ 3. 验证租户（TODO：数据迁移后）  │
│    - 检查租户是否存在            │
│    - 检查租户是否激活            │
│    - 检查租户是否被删除          │
└────────┬────────────────────────┘
         │
         ▼
┌─────────────────────────────────┐
│ 4. 注入context                   │
│    - ctxcache.Store(...)         │
│    - ctx.Set(TenantIDKey, ...)   │
└────────┬────────────────────────┘
         │
         ▼
┌─────────────────────────────────┐
│ 5. 记录追踪和日志                │
│    - tracing.AddSpanAttributes   │
│    - logs.CtxInfof               │
└────────┬────────────────────────┘
         │
         ▼
┌─────────────┐
│ Next Handler │
└──────────────┘
```

### 数据流

```
Client Request
    │
    ├─> X-Tenant-ID Header
    ├─> Session Cookie
    └─> JWT Token
         │
         ▼
TenantIsolationMiddleware
    │
    ├─> Extract tenant_id
    ├─> Validate tenant
    └─> Inject to context
         │
         ▼
Business Handler
    │
    ├─> GetTenantIDFromContext()
    ├─> Query with tenant_id
    └─> Return tenant-scoped data
```

## ⚠️ 注意事项

### 当前限制（数据迁移前）

1. **Session没有TenantID字段**
   - 当前Session实体只有`UserID`, `Locale`, `UserEmail`
   - **影响**: 无法从Session中提取tenant_id
   - **解决方案**: 使用HTTP Header传递tenant_id

2. **User表没有TenantID字段**
   - 当前users表没有`tenant_id`列
   - **影响**: 用户与租户没有关联关系
   - **解决方案**: 执行数据迁移添加`user_tenant`关联表

3. **使用默认租户ID**
   - 当前当无法提取tenant_id时，使用`DefaultTenantID = "default"`
   - **影响**: 临时兼容模式，无法强制租户隔离
   - **解决方案**: 数据迁移后移除默认值逻辑

### 数据迁移后（TODO）

1. **Session添加TenantID字段**

   type Session struct {

3. **创建user_tenant关联表**（支持用户多租户）

## 🔒 安全最佳实践

### 1. 永远不要信任客户端输入

```go
// ❌ 错误：直接使用客户端提供的tenant_id查询数据
func ListBots(tenantID string) ([]*Bot, error) {
    return db.Where("tenant_id = ?", tenantID).Find(&bots).Error
}

// ✅ 正确：从context中提取经过验证的tenant_id
func ListBots(ctx context.Context) ([]*Bot, error) {
    tenantID := middleware.GetTenantIDFromContext(ctx)
    return db.Where("tenant_id = ?", tenantID).Find(&bots).Error
}
```

### 2. 数据库查询强制添加tenant_id过滤

```go
// ❌ 错误：没有tenant_id过滤，可能泄露其他租户数据
func GetBot(ctx context.Context, botID string) (*Bot, error) {
    var bot Bot
    err := db.Where("bot_id = ?", botID).First(&bot).Error
    return &bot, err
}

// ✅ 正确：强制添加tenant_id过滤
func GetBot(ctx context.Context, botID string) (*Bot, error) {
    tenantID := middleware.GetTenantIDFromContext(ctx)
    var bot Bot
    err := db.Where("bot_id = ? AND tenant_id = ?", botID, tenantID).First(&bot).Error
    return &bot, err
}
```

### 3. GORM自动作用域（推荐）

```go
// 创建租户作用域
func TenantScope(tenantID string) func(db *gorm.DB) *gorm.DB {
    return func(db *gorm.DB) *gorm.DB {
        return db.Where("tenant_id = ?", tenantID)
    }
}

// 使用作用域
func ListBots(ctx context.Context) ([]*Bot, error) {
    tenantID := middleware.GetTenantIDFromContext(ctx)

    var bots []*Bot
    err := db.Scopes(TenantScope(tenantID)).Find(&bots).Error
    return bots, err
}
```

### 4. 服务层强制租户隔离

```go
type BotService struct {
    repo BotRepository
}

func (s *BotService) CreateBot(ctx context.Context, req *CreateBotRequest) (*Bot, error) {
    // 必须从context获取tenant_id
    tenantID := middleware.MustGetTenantIDFromContext(ctx)

    // 自动关联租户
    bot := &Bot{
        BotID:    generateID(),
        TenantID: tenantID, // 强制关联租户
        Name:     req.Name,
        // ...
    }

    return s.repo.Create(ctx, bot)
}
```

## 🐛 故障排查

### 常见问题

#### 1. "missing or invalid tenant_id" 错误

**原因**: 客户端没有提供有效的tenant_id

**解决方案**:
```bash
# 添加X-Tenant-ID Header
curl -H "X-Tenant-ID: your-tenant-id" http://localhost:8888/api/bots
```

#### 2. Context中没有tenant_id

**原因**: 业务处理器在中间件之前执行

**解决方案**: 确保中间件注册顺序正确
```go
// ✅ 正确顺序
h.Use(middleware.SessionAuthMW())      // 1. 先验证Session
h.Use(middleware.TenantIsolationMiddleware()) // 2. 再提取tenant_id
h.GET("/api/bots", listBots)           // 3. 最后执行业务逻辑

// ❌ 错误顺序
h.GET("/api/bots", listBots)           // 业务逻辑在中间件之前
h.Use(middleware.TenantIsolationMiddleware())
```

#### 3. 数据查询结果为空

**原因**: 查询时没有添加tenant_id过滤条件

**解决方案**: 检查SQL是否包含`WHERE tenant_id = ?`
