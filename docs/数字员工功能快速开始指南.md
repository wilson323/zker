## 📖 核心概念

### 什么是数字员工？

数字员工是AI驱动的虚拟员工，具有：
- **画像**: 角色、技能、性格特征
- **任务**: 可分配客服、销售、技术支持等任务
- **绩效**: 完成率、响应时间、客户评分

### 角色类型

| 角色 | 说明 | 典型技能 |
|------|------|----------|
| customer_service | 客服 | 客户咨询、问题解答、订单查询 |
| sales | 销售 | 产品推荐、跟进客户、促成交易 |
| tech_support | 技术支持 | 故障排查、技术指导、问题解决 |
| consultant | 顾问 | 业务咨询、方案建议、专业建议 |
| trainer | 培训师 | 知识传递、技能培训、答疑解惑 |

### 任务类型与角色匹配

```
customer_service 任务 → 分配给 customer_service 员工
sales_follow 任务     → 分配给 sales 员工
tech_support 任务     → 分配给 tech_support 员工
```

### 技能匹配算法

```go
// 自动分配任务时，系统会：
1. 根据任务类型筛选匹配的员工
2. 检查员工是否具备必需技能（JSON_CONTAINS）
3. 选择第一个可用的员工（后续可优化为负载均衡）
```

### 场景1：创建客服团队

```go
// 创建5个客服员工
for i := 1; i <= 5; i++ {

```

### 场景2：批量分配任务

```go
// 为新到的10个客服咨询任务自动分配
tasks := []string{"task-1", "task-2", ..., "task-10"}
for _, taskID := range tasks {
    req := &entity.AutoAssignTaskRequest{
        TaskID:         taskID,
        TaskType:       entity.TaskTypeCustomerService,
        Priority:       entity.TaskPriorityMedium,
        RequiredSkills: []string{"客户咨询"},

    service.AutoAssignTask(ctx, req)
}
// 系统自动将任务平均分配给5个客服员工
```

## 🔧 集成到现有系统

### Application层初始化

创建文件：`backend/application/digital_employee/init.go`

```go
package digital_employee

import (
    "gorm.io/gorm"
    "github.com/coze-dev/coze-studio/backend/domain/digital_employee/internal/dal"
    "github.com/coze-dev/coze-studio/backend/domain/digital_employee/service"
)

var (
    ProfileRepo     repository.ProfileRepository
    TaskRepo        repository.TaskAssignmentRepository
    PerformanceRepo repository.PerformanceRepository

    ProfileSvc     service.ProfileService
    TaskSvc        service.TaskService
    PerformanceSvc service.PerformanceService

    ServiceContainer *service.Container
)

// Init 初始化数字员工模块
func Init(db *gorm.DB) error {
    // 初始化Repository
    ProfileRepo = dal.NewProfileDAL(db)
    TaskRepo = dal.NewTaskAssignmentDAL(db)
    PerformanceRepo = dal.NewPerformanceDAL(db)

    // 初始化Service
    ServiceContainer = service.NewContainer(
        ProfileRepo,
        TaskRepo,
        PerformanceRepo,
    )

    ProfileSvc = ServiceContainer.Profile
    TaskSvc = ServiceContainer.Task
    PerformanceSvc = ServiceContainer.Performance

    return nil
}
```

### 路由注册

在 `backend/api/router/coze/api.go` 中添加：

```go
import digitalemployeeapp "github.com/coze-dev/coze-studio/backend/application/digital_employee"

func registerDigitalEmployeeRoutes(r *hertz.Router) {
    api := r.Group("/api/v1/digital-employees")

    // 员工画像
    api.POST("", middleware.AuthRequired(), coze.CreateEmployeeProfile)
    api.PUT("/:employee_id", middleware.AuthRequired(), coze.UpdateEmployeeProfile)
    api.GET("/:employee_id", coze.GetEmployeeProfile)
    api.GET("", coze.ListEmployeeProfiles)
    api.DELETE("/:employee_id", middleware.AuthRequired(), coze.DeleteEmployeeProfile)

    // 任务分配
    api.POST("/tasks/assign", middleware.AuthRequired(), coze.AssignTask)
    api.POST("/tasks/auto-assign", middleware.AuthRequired(), coze.AutoAssignTask)
    api.PUT("/tasks/:assignment_id/complete", middleware.AuthRequired(), coze.CompleteTask)
    api.PUT("/tasks/:assignment_id/fail", middleware.AuthRequired(), coze.FailTask)
    api.GET("/:employee_id/tasks", coze.GetEmployeeTasks)

    // 绩效统计
    api.GET("/:employee_id/performance", coze.GetEmployeePerformance)
    api.GET("/performance/team", coze.GetTeamPerformance)
}
```

## 🐛 常见问题

### Q1: 编译错误 "missing parameter type"

**解决**: 确保所有返回参数都有类型定义：

```go
// ❌ 错误
func foo() (a, b, c int, error)

// ✅ 正确
func foo() (a int, b int, c int, err error)
```

### Q2: 数据库迁移失败

**解决**: 检查MySQL版本是否≥8.0，确保tenants表已存在：

```bash
# 检查表是否存在
mysql -u root -p
USE opencoze;
SHOW TABLES LIKE 'digital_employee%';
```

### Q3: 单元测试失败

**解决**: 确保已安装testify：

```bash
go get github.com/stretchr/testify
```

### Q4: API返回404

**解决**: 检查路由是否正确注册：

```bash
# 查看已注册的路由
curl http://localhost:8080/api/v1/digital-employees
```
