# RBAC权限系统开发助手

协助 RBAC（基于角色的访问控制）权限系统开发，确保5级数据权限和3级字段权限。

## 使用场景

当你需要开发权限相关功能时，使用此技能：
- 创建角色和权限实体
- 实现数据权限检查
- 实现字段权限过滤
- 设计权限中间件

## 功能

- 生成符合规范的角色实体代码
- 生成权限检查服务代码
- 提供数据权限最佳实践
- 生成权限中间件代码
- 生成权限配置示例

## 输入

- **功能类型**：entity、service、middleware、config
- **资源类型**：bots、conversations、knowledge、workflows、plugins
- **权限级别**：ALL、DEPARTMENT、OWN、CUSTOM、NONE

## 输出

- 生成的代码框架
- 权限检查逻辑
- 数据过滤建议
- 相关规范文档链接

## 示例

```
为 bots 表实现5级数据权限检查服务
```
