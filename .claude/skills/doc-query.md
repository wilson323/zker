# 企业级文档查询

快速查询企业级功能完善相关的所有设计文档、规范文档和开发文档。

## 使用场景

当你需要查找设计文档、规范或开发指南时，使用此技能：
- 查找特定功能的API文档
- 查找特定技术组件的使用指南
- 查找特定开发规范
- 查找故障排查指南
- 查找个人开发计划

## 功能

- 快速检索80+份企业级文档
- 按类别过滤文档（设计、规范、开发、运维）
- 按角色过滤文档（研发A/B/C/D）
- 提供文档摘要和关键链接
- 推荐相关文档

## 输入

- **查询关键词**：文档主题或功能名称
- **文档类别**：design、spec、plan、ops、all
- **目标角色**：devA、devB、devC、devD、all

## 输出

- 相关文档列表
- 文档摘要
- 关键章节链接
- 相关文档推荐

## 示例

```
查询多租户架构设计文档
查询研发B的开发计划
查询所有API设计规范
```
