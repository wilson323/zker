# 多租户开发助手

协助多租户架构相关的开发工作，确保租户隔离和配额管理。

## 使用场景

当你需要开发多租户相关功能时，使用此技能：
- 创建租户实体和仓储
- 实现配额检查逻辑
- 添加租户隔离中间件
- 设计订阅管理功能

## 功能

- 生成符合规范的租户实体代码
- 生成配额检查服务代码
- 提供租户隔离最佳实践
- 检查是否遗漏租户隔离
- 生成数据库迁移脚本

## 输入

- **功能类型**：entity、service、middleware、migration
- **资源类型**：bots、conversations、knowledge 等
- **目标表名**：要操作的数据库表

## 输出

- 生成的代码框架
- 实现建议
- 相关规范文档链接
- 测试用例示例

## 示例

```
为 conversations 表创建租户隔离的实体和服务
```
