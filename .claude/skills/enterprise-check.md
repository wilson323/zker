# 企业级规范检查

检查代码和设计是否符合企业级开发规范。

## 使用场景

当你需要检查代码、设计或架构是否符合企业级开发规范时，使用此技能。

## 功能

- 检查代码命名是否符合规范
- 检查函数/组件设计是否符合 SOLID 原则
- 检查错误处理是否使用统一错误码
- 检查数据库表设计是否符合规范
- 检查 API 设计是否符合 RESTful 规范
- 检查是否有全局一致性问题

## 输入

- **文件路径或代码片段**：要检查的代码
- **检查类型**：backend、frontend、database、api 或 all
- **检查级别**：L1（个人）、L2（模块）、L3（集成）或 L4（发布）

## 输出

- 检查结果报告（通过/不通过）
- 不符合规范的项目列表
- 改进建议
- 相关规范文档链接

## 示例

```
检查 backend/domain/tenant/service 的代码是否符合企业级开发规范
```
