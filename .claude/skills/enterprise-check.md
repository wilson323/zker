# 企业级规范检查

**版本**: v3.0.0 | **更新**: 2025-01-03

检查代码和设计是否符合企业级开发规范。

---

## 🎯 使用场景

- 代码审查前的预检查
- 全局一致性检查
- 架构设计验证

---

## 🔍 检查内容

### 代码规范

- [ ] 命名符合规范
- [ ] 函数/组件设计（SOLID 原则）
- [ ] 错误处理（统一错误码）
- [ ] 并发安全（如有并发）

### 架构规范

- [ ] DDD 分层清晰
- [ ] 多租户隔离完整
- [ ] RBAC 权限检查
- [ ] API 符合 RESTful 规范

### 数据库规范

- [ ] 表命名符合规范
- [ ] 字段命名符合规范
- [ ] 所有必要索引已创建
- [ ] 使用 deleted_at 软删除

---

## 📋 检查级别

| 级别 | 说明 | 检查内容 |
|------|------|---------|
| **L1（个人）** | 代码风格、命名、基础逻辑 | 代码质量 |
| **L2（模块）** | 模块间接口、数据一致性 | 模块集成 |
| **L3（集成）** | 跨模块集成、端到端流程 | 系统集成 |
| **L4（发布）** | 完整性、安全性、向后兼容 | 发布质量 |
